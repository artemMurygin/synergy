# Листы «МБ ПО» и «МБ ПО » (профессиональное обучение, ПО)

**Название:** в книге два листа: «МБ ПО» (15 строк, только пары «профессия — дисциплины», без привязки к факультетам) и «МБ ПО » с пробелом в конце названия (22 строки, с факультетами). Колонка H листа «БАКСПЦ» связана с вторым. Если инструмент возвращает короткий вариант (строки «Социальный работник», «Вожатый», … в колонках A–B), нужная таблица недоступна под этим именем.

**Что это:** описание программ профессионального обучения (дополнительной профессии «ПО»), которое студент бакалавриата получает вместе с дипломом. Строка 1 — заголовок: «Профессиональное обучение (курс продолжительностью 2 164 ч. для БАК, 1 444 ч. для МАГ)», строка 2 — шапка. Данные в строках 3–21 (19 строк).

Профессии «Ассистент экскурсовода (гид)» (факультеты Лингвистики — строка 6, Туризма — строка 16) и «Агент по закупкам» (Бизнеса — строка 8, Менеджмента — строка 12) повторяются, выбирай по факультету. Ссылки из «БАКСПЦ» (колонка H, `gid=276321944`, не относится к известным листам книги; по содержимому это «МБ ПО ») ведут на строку **на 1 выше** нужной (верно 0 из 26; у 3 ячеек ссылки нет — строки 116, 123, 132).
