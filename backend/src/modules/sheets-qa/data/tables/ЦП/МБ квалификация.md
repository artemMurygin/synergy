# Лист «МБ квалификация» (проект «Квалификация»)

**Что это:** описание проекта «Квалификация» — дополнительной квалификации, которую студент СПО получает вместе с дипломом (колонка F листа «СПО»). Строки 2–39, одна строка — один проект для одного факультета (названия проектов повторяются для разных факультетов, меняется только речевой модуль).

| Колонка | Содержание                                                                                                                                            |
| ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| A       | Факультет                                                                                                                                             |
| B       | Название проекта: «Комьюнити-менеджмент», «Графический дизайнер», «Бизнес-аналитик», «Менеджер проектов (Project manager)», «SMM-маркетолог» и другие |
| C       | «Речевой модуль вход» — что говорить абитуриенту этого факультета о пользе проекта                                                                    |
| D       | Стоимость (например, 30 000 ₽)                                                                                                                        |
| E       | Варианты оплаты (например, «Кредит POS, Сплит, Своими»)                                                                                               |
| F       | Срок обучения (например, «2 месяца», «6 месяцев»)                                                                                                     |
| G       | Презентация (ссылка на PDF)                                                                                                                           |
| H       | Учебный план (ссылка на PDF)                                                                                                                          |
| I       | Демо-доступ: ссылка `do.synergy.ru` и учётные данные демо-аккаунта — **служебная информация, абитуриенту не сообщать**                                |
| J       | Бриф (ссылка на другой лист этой книги по `gid`)                                                                                                      |

Лист общий для [СПО](СПО.md) и [БАКСПЦ](БАКСПЦ.md): связь по названию проекта и ближайшему факультету, см. `find_related`.
