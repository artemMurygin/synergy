# Лист «МБ СПО» (методическая база СПО)

**Что это:** описание каждой программы СПО для консультации абитуриента. Строки 2–59, одна строка — одна программа (с дублями, см. ниже). Строка 1 — шапка.

| Колонка | Содержание                                                                                                              |
| ------- | ----------------------------------------------------------------------------------------------------------------------- |
| A       | «ЦП» — обратная ссылка на лист «СПО»                                                                                    |
| B       | Факультет и адрес корпуса                                                                                               |
| C       | Специальность и квалификация (через перенос строки); ссылка на страницу программы на сайте `synergy.ru`                 |
| D       | «О программе / Преимущества» — текст описания; ссылка на презентацию                                                    |
| E       | «Преподавателями на факультете будут» — ФИО, должности, регалии                                                         |
| F       | «В процессе обучения Вы будете изучать такие дисциплины, как» — список дисциплин                                        |
| G       | «В процессе обучения Вы будете проходить практику в» — партнёры для практики                                            |
| H       | «После окончания данного факультета Вы сможете стать» — профессии и карьера; иногда зарплаты и «Квалификация в дипломе» |
| I       | «Успешные студенты» — выпускники, истории успеха; заполнена не у всех                                                   |
| J       | «Дополнительная информация» — ссылка на материалы; заполнена не у всех                                                  |
| K       | «УП» — ссылка на папку Google Drive с учебным планом программы                                                          |
| L       | «ПП» — «Общая по фак.»: ссылка на общую папку факультета на Google Drive                                                |

**Особенности:**

- Строки 14/24, 53/57, 54/58, 55/59 — дубли (одна и та же программа записана дважды); для ответов берите любую из пары.
- Строка 25 («Факультет кино и телевидения», «Актерское искусство» без квалификации) — повторная запись; рабочая запись — строка 10 («Театр, кино и телевидение», «Актёр (кино)»).
- Строка 56 («Нейроанимация», «Нейроаниматор») — в листе «СПО» такой программы нет.
- Строка 36 называется «Информационные системы и программирование» (в «СПО» — «Разработка и управление программным обеспечением 09.02.11», программист); строка 45 — «Мехатроника и мобильная робототехника» (в «СПО» — «Мехатроника и робототехника (по отраслям) 15.02.10»); названия различаются, это одна и та же программа.
- Цен на листе нет: цены только в «СПО».

Связанный лист с ценами: [СПО](СПО.md). Связь программ — `find_related` (по гиперссылкам прайса; названия могут отличаться: специальность включает несколько профессий).
