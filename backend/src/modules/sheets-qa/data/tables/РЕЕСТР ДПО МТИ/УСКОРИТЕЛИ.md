# Лист «УСКОРИТЕЛИ» (скрытый) книги «РЕЕСТР ДПО МТИ - 29.09.2026-2.xlsx»

**Что это:** справочник пакета «Максимум PRO 2в1 ВО+ДПО» (A1): программы ДПО, которые сокращают срок высшего образования (ВО) до 3 лет. Для каждой из 8 программ ДПО лист даёт файлы-образцы (диплом, учебные планы по трём тарифам, презентацию), название программы с квалификацией и список направлений ВО, к которым программа подходит. Цен по направлениям ВО на листе нет: есть только цены трёх тарифов ДПО в A1. Нужен менеджеру, чтобы ответить на вопросы «какая программа ДПО ускорит конкретное направление ВО» и «где взять учебный план или презентацию».

## Как искать нужное

- По направлению ВО: искать в колонке E:H, затем смотреть программу ДПО в D той же объединённой группы строк (A–D относятся ко всему блоку).
- По программе: колонка D; для документов — A (диплом), B (УП), C (презентация).
- Цена: только A1 (три тарифа). Для конкретного направления ВО она одинаковая.
- Примеры: «Психология» (строка 7) → «Основы управления проектами», без квалификации; «Прикладная информатика» (строка 20) → «Информационные системы в бизнес-процессах», квалификация «Специалист по информационным системам»; «Дизайн» (строка 26) → «Графический дизайн и визуальные коммуникации», «Графический дизайнер».
