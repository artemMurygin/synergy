# Структура книги «Театральный фактультет.xlsx»

Справочник продуктов театрального факультета (в имени файла «фактультет» с опечаткой): колледж, специалитет, магистратура, ДПО для взрослых. Подробное описание листа читай (`read_sheet_guide`) только если собираешься работать с этим листом.

## Описанные листы

| **Главная**      | Описание титульного листа «Главная» театрального факультета (ТФ).
