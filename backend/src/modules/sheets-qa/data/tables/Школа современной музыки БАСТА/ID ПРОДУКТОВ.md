# Лист «ID ПРОДУКТОВ» (справочник ID продуктов ГП БАСТА, скрытый)

**Что это:** служебный справочник соответствия «продукт — числовой ID» для программ школы БАСТА. Каждому названию продукта (программа, объём, школа, число из названия) сопоставлены ID, по два ID на продукт (у шести продуктов по четыре). Назначение ID в книге не объяснено. По смыслу и по «Аббревиатуры.md» (ГП, «ID для ЦИ») это идентификаторы продуктов для CRM; это предположение. Цен, дат, форматов и описаний на листе нет.

**Размер и шапка:** статус **скрытый**. Формально 994 строки × 5 колонок (A–E), реально заполнены строки 1–103: строка 1 шапка, строки 2–103 данные (102 строки, 102 разных ID, повторов ID нет). Строки 104–994 пустые, в них заполнена только колонка E. Заморозки нет. Скрытых строк и колонок нет. Объединение одно: E1:E994 (вся колонка E).

## Колонки

| Колонка | Заголовок     | Содержание                                                                                                                                    |
| ------- | ------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| A       | Уровень       | `ДО` (70 строк) или `ДПО` (32 строки)                                                                                                         |
| B       | Подуровень    | `ДОП` у всех строк «ДО», `ППК` у всех строк «ДПО»                                                                                             |
| C       | Специальность | Название продукта в форме «Название [объём], Школа, число», например «Вокал 24, Баста, 87». Каждое название встречается 2 или 4 раза          |
| D       | ID            | Число, 9 цифр. Уникально в пределах листа                                                                                                     |
| E       | ГП БАСТА      | Одна объединённая ячейка «ГП БАСТА» на весь лист: метка группы продуктов. Расшифровка «ГП» в книге нет, в `Аббревиатуры.md` это предположение |

## Как читать название продукта (колонка C)

Структура названия: `<программа> [<объём>[ДО|ПК]], <школа>, <число>`. Расшифровки ниже являются **предположениями**, книга их не подтверждает:

- Число в конце (`27`, `87`, `177`, `363`) принимает четыре значения; по росту вместе с объёмом похоже на стоимость в тысячах рублей или на условный тариф, но на листе нет ни единицы измерения, ни ссылки на прайс. Агент не должен трактовать это число как цену.
- Число в середине (`8`, `24`, `48`, `96`) похоже на объём программы (часы или занятия); единица не указана. Суффиксы `ДО` и `ПК` после числа (например «Вокал 96ДО» и «Вокал 96ПК») совпадают с уровнями А: `ДО` и `ПК` (повышение квалификации по `Аббревиатуры.md`); связь с колонкой A (уровень «ДПО/ППК») точно не проверена.
- Школа в названии: `Баста`, `ШМС`, `ШСМ`, `ФМИ` (последнее встречается только в «Сонграйтинг, ФМИ, 87»). `ШМС` и `ШСМ` могут быть одной школой с разным порядком букв (опечатка) — см. вопросы.
- В названиях встречаются «со звездой» (программа с приглашённым артистом, предположение) и «дети» (детская версия).

## Связи с другими листами

- Формул и гиперссылок на листе нет; ссылок на него из других листов не найдено. ID из колонки D не встречаются на других листах книги (проверено поиском значений по всем листам).
- Названия продуктов не совпадают дословно с названиями на листах «РЕЕСТР ПРОГРАММ» и «ДПО …» (в «РЕЕСТР ПРОГРАММ» другой набор колонок: направление, срок, цена, дата старта; содержимое построчно не сверялось). Соответствие нужно искать по смыслу: например, «Музыкальный продакшн», «Музыкальный менеджмент», «Сонграйтинг», «Концертный продакшн» есть и в названиях листов «ДПО …», и здесь.
- Внешних ресурсов на листе нет. На листе есть пустой рисунок (drawing) без содержимого.
- Комментариев к ячейкам нет.

## Как искать

- Нужен ID продукта: найти строку по колонке C (название), взять D. Если у названия два или четыре ID, различий между ними на листе нет — не выбирать вслепую, а уточнять у владельца таблицы.
- Цену, срок, формат и описание этого листа брать нельзя: смотреть «РЕЕСТР ПРОГРАММ» и листы «ДПО …».

## Вопросы и замечания

1. Лист скрыт и без пояснений: что означает ID (CRM, платёжная система, ЦИ) и в какой системе он действует?
2. Почему у каждого продукта по 2 ID (у шести по 4) и чем они различаются? Колонки-различителя нет.
3. Что значит число в конце названия (`27`, `87`, `177`, `363`) и число в середине (`8`, `24`, `48`, `96`)?
4. `ШМС` и `ШСМ` — одна школа или разные? Возможна опечатка («Музыкальный продакшн, ШМС» против «Музыкальный менеджмент, ШСМ»).
5. Что такое `ФМИ` (встречается только в «Сонграйтинг, ФМИ, 87»)?
6. Названия не унифицированы: «Инструментальное исп» и «Инструмент исп со звездой» сокращены по-разному, в одних названиях нет суффикса `ДО/ПК` («Вокал 24», «Вокал со звездой 24, 48»), в других есть.
7. Колонка E объединена на 994 строки, хотя данных всего 102: хвост из 891 пустой строки только с меткой «ГП БАСТА».
8. На листе нет ни дат, ни цен: определить актуальность ID нельзя.
