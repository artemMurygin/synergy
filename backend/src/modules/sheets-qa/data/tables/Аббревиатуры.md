# Аббревиатуры и непонятные термины книги «ЦП»

Рабочий список сокращений и терминов, которые встречаются в книге. Сюда добавляется всё, что не удалось расшифровать при описании листов; когда владелец таблицы подтвердит расшифровку, статус меняется. Файл не отдаётся агенту: это рабочий документ. Подтверждённые расшифровки нужно перенести в описания листов (`ЦП/<лист>.md`), чтобы агент мог объяснить термин менеджеру.

Список составлен сканированием всей книги (35 листов): места указаны по реальным ячейкам. Если место не указано, значит, на этом листе термин найден не был.

## Как добавлять

1. Добавьте строку в таблицу, в алфавитном порядке.
2. В колонке «Где встречается» укажите лист и ячейки; в колонке «Как используется» напишите, что видно из самой книги, без догадок. Цитаты берите из ячеек.
3. Статусы: `✅` расшифровка подтверждена книгой или владельцем; `❓` есть правдоподобное предположение; `⬜` не расшифровано.
4. Подтверждённую расшифровку пишите в колонку «Расшифровка», предположение в колонку «Предположение», источник подтверждения в колонку «Источник».
