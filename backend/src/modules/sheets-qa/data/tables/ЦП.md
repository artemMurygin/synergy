## Листы без отдельного описания

Читай их только по прямой просьбе менеджера; без описания колонок ответ может быть неточным, предупреди об этом.

- Справочные листы, упомянутые в описании БАКСПЦ: **Рег ставки** (региональные ставки на дистанционное обучение и ПКО онлайн), **Способы оплаты**, **Скидки Синергия и МАП** (регламент: клиентам скидки не направлять).
- Остальные листы (по названиям; назначение не описано): Онлайн школа, ЕГЭОГЭ, Репетиторы, Международка, МБ международка, Курсы, Курсы факультетов, МБ Школа, Памятка по группам продуктов, Контакты визуалов, Поступление без визы.

## Как листы связаны между собой

```
СПО ──(колонка V «МБ»)──────────────► МБ СПО        одна строка программы ↔ одна строка методической базы
СПО ◄─(колонка A «ЦП»)──────────────  МБ СПО        обратная ссылка
СПО ──(колонка F «Проект Квалификация»)► МБ квалификация   проект «Квалификация» ↔ его описание и цена
СПО ──(колонка E, колонка U, колонка W)► внешние ресурсы (другая книга, LMS, Google Drive)

БАКСПЦ ──(колонка Z «МБ ВО»)────────► МБ БАК         одна строка программы ↔ одна строка методической базы
БАКСПЦ ◄─(колонка A «ЦП»)───────────  МБ БАК         обратная ссылка
БАКСПЦ ──(колонка G «Квалификация»)──► МБ квалификация   проект «Квалификация» ↔ его описание и цена
БАКСПЦ ──(колонка H «ПО»)───────────► МБ ПО (лист с пробелом в конце имени)   профессия, которую получает студент
БАКСПЦ ◄─(колонка B «ЦП»)───────────  МБ ПО          ссылка на строку факультета
БАКСПЦ ──(колонки F, V, W, X, AA)───► внешние ресурсы (другая книга, LMS, Google Drive, листы вне книги)
```

**Связи между листами.** Гиперссылки в книге ведут с прайса на строку описания программы в методической базе, на проект «Квалификация» и т. д. Инструмент `find_related(sheet, row)` берёт связи из этих гиперссылок. Связи по гиперссылкам настроены для прайсов СПО, БАКСПЦ, МАГ, АСПОРД, МТИ, МАП и ЮФУБГИСПИГ (вместе с их листами «МБ …» и «МБ квалификация»); у МВА, Филиалов и Дубая таких связей нет. Если у строки СПО нет гиперссылки, он ищет по названиям факультета, специальности и квалификации и ставит пометку `matched by names, no hyperlink; verify` — это предположение, о нём нужно предупредить менеджера. Пометка `link target has a different name; verify` значит, что гиперссылка есть, но название программы в целевой строке заметно отличается от названия в прайсе (ошибочная или спорная ссылка): тоже предупреди менеджера и сверь описание. Для листов «МБ …» инструмент возвращает строки прайса, которые на них ссылаются (по ссылкам прайса, колонка «ЦП» самой методической базы ненадёжна). Названия в прайсе и в методической базе могут не совпадать, потому что специальность включает несколько профессий и профилей; расхождение названий — не ошибка. Подробности — в описании листа-прайса ([СПО.md](ЦП/СПО.md), [БАКСПЦ.md](ЦП/БАКСПЦ.md)).
