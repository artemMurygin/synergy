# sheets-qa

Агент по ценам: специалист по ценовой политике, который отвечает на вопросы об обучении, читая выгруженные книги (`ЦП.xlsx` и другие) через инструменты. Модуль содержит только этого агента: книги, инструменты, подагенты по уровням, системный промпт и данные. Он экспортирует возможность `SheetsQaAgentCapability` (контракт `shared/agent-capability`) и `BookLibraryPort`.

Чаты, HTTP-маршруты, запуск агента, стриминг AG-UI, отмена и checkpointer живут в модуле `assistant` (см. `../assistant/README.md`). Оркестратор ассистента подключает эту возможность как подагента `sheets_qa` с режимом `isolated`: агент по ценам получает вопрос одним текстом, без истории чата, и сам ничего не хранит. Модуль не зависит от `assistant`.

## Как пользоваться

1. Положите книгу в `data/tables/ЦП.xlsx` (содержимое папки не коммитится). Заменили файл, агент увидит новые данные при следующем вопросе.
2. Структура книги описана в `data/tables/ЦП.md` (рядом с книгой), подробные описания листов лежат в `data/tables/ЦП/<лист>.md`. `data/catalog.md` кратко говорит агенту о книгах и подставляется в системный промпт. Описания агент читает по запросу инструментом `read_sheet_guide`, поэтому лишнее в контекст не попадает.
3. Запустите бэкенд из папки `backend` и задайте вопрос через чат ассистента (маршруты `POST /threads`, `POST /agent`, заголовок `X-Client-App`): см. `../assistant/README.md`. Оркестратор сам передаст ценовой вопрос агенту по ценам.

## Настройки

В `sheets-qa.config.ts`: модели (основная и подагентов), пути, список книг (`SHEETS_QA_BOOKS`, книга по умолчанию `DEFAULT_BOOK`), подагенты по уровням (`SEARCHERS`), лимиты, раскладка листов (`SHEET_LAYOUTS`: строки шапки, первая строка данных, скрытые колонки), исключения для связей (`RELATION_OVERRIDES`). Ключи и адреса моделей (`OPENAI_API_KEY`, `OPENAI_BASE_URL`, `OPENROUTER_API_KEY`) берутся из env.

## Инструменты агента (только чтение)

`read_sheet_guide` (структура книги и описания листов), `list_sheets`, `search_cells` (несколько запросов за вызов), `read_rows` (с подписями колонок из шапки и секцией — факультетом), `get_row_links`, `find_related` (связи прайсов СПО, БАКСПЦ, МАГ, АСПОРД, МТИ, МАП, ЮФУБГИСПИГ с их листами «МБ …» и «МБ квалификация» по гиперссылкам книги, которые читаются из XML; правила — `LINK_RELATIONS` в конфиге: целевой лист, блок строк, колонки названия для проверки; ссылка на программу с другим названием возвращается с пометкой `link target has a different name; verify`; для СПО без ссылки — сопоставление по названиям с пометкой `matched by names`).

## Структура

- `domain/ports` — порты библиотеки книг (`BookLibraryPort`), ридера книги и описаний листов.
- `application` — реестр книг (`BookRegistry`) и фабрика инструментов (`createSheetTools`).
- `infrastructure` — `ExcelJsWorkbookReader`, сопоставление по названиям, чтение описаний листов, подагенты по уровням, системный промпт и `SheetsQaAgentCapability`, которая собирает вложенный Deep Agent.
- `sheets-qa.module.ts` — провайдеры библиотеки книг и возможности, экспорт `BookLibraryPort` и `SheetsQaAgentCapability`.

Контроллеров, use case'ов чатов и миграций чатов здесь нет: всё это в `assistant`.

## Как добавить лист

Создайте `data/tables/ЦП/<название листа>.md`, добавьте строку в таблицу `data/tables/ЦП.md` и, если у листа многоуровневая шапка, раскладку в `SHEET_LAYOUTS`.
