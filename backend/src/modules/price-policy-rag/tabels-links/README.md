# Группы связанных листов для Programs ETL

Снимок от 2026-11-03. Проверены метаданные семи Google-таблиц и первые строки каждого видимого листа. Все 82 видимых листа распределены по 20 группам; скрытые листы и копии не включены. Точные идентификаторы и ссылки на каждый лист — в [`groups.json`](./groups.json). Дополнительная проверка связей по строкам — в [`analysis.md`](./analysis.md).

Группы — задания серверному агенту. `ready` означает очевидную связь по структуре; `needs_matching` требует подтверждения соответствия программ при полном чтении; `out_of_scope_schema` и `deferred` не следует загружать как программы без отдельного решения.

Структурированный ответ агента должен соответствовать сущностям из [архитектуры add-programs-etl-pipeline](../../../../../openspec/changes/add-programs-etl-pipeline/architecture.md): `program`, `offer`, `price`, `entrance_requirement`, `content_chunk`, справочники и источники `source_sheet`/`raw_row`. Этот файл описывает состав входных групп, а не новую схему ответа.

## Правила связывания

- Сохранять `spreadsheet_id`, `sheet_id` и номер строки для каждой извлечённой записи. Связывать МБ с программой только при подтверждённом совпадении организации, уровня и названия/профиля; одинаковые названия у разных организаций не объединять.
- Тематические листы, общие реестры и отдельные прайсы могут повторять программу. Они являются дополнительными источниками, пока не подтверждены идентичность программы и условия цены.
- Общие скидки, региональные ставки, способы оплаты и группы продуктов извлекать один раз; не создавать их копии в каждой группе программ.
- Секреты в ячейках исключать до передачи агенту и записи `raw_row`. В просмотренных листах есть данные доступа к демо-курсам.
- `content_chunk` требует `program_id`, поэтому общий FAQ продаж без установленной программы нельзя записать как `faq`. В текущей схеме также нет уровня `school`.
- Для нескольких групп просмотрены только первые строки: связи `Международка` ↔ `МБ международка`, ординатура ↔ `МБ АСП`, а также пересечения Академии с реестрами ДПО требуют проверки при полном чтении.
