## ADDED Requirements

### Requirement: Список чатов в обоих приложениях
Требования этой capability к списку чатов, созданию, переключению, переименованию, удалению и восстановлению чата SHALL выполняться одинаково в `control-center` и в боковой панели `manager-helper`. Строка списка MUST быть компактной: название чата в одну строку, время последней активности и индикатор, если в чате идёт ответ агента. Форма быстрого подбора MUST показываться только в `manager-helper`.

#### Scenario: Список чатов в control-center
- **WHEN** пользователь `control-center` открывает раздел «Чаты»
- **THEN** список чатов выглядит и работает так же, как в `manager-helper`, но без формы быстрого подбора

#### Scenario: Чат с идущим ответом
- **WHEN** в одном из чатов агент ещё отвечает
- **THEN** строка этого чата в списке показывает индикатор работы

### Requirement: Скрытие списка чатов
В десктопном и планшетном режимах пользователь SHALL иметь возможность скрыть список чатов кнопкой и показать его снова. Пока список скрыт, чат MUST занимать освободившееся место. Состояние «скрыт / показан» MUST сохраняться в рамках сеанса.

#### Scenario: Скрытие списка на десктопе
- **WHEN** пользователь `control-center` нажимает кнопку скрытия списка чатов
- **THEN** список скрывается, чат расширяется на освободившееся место, а кнопка позволяет вернуть список

### Requirement: Поиск по чатам
Над списком чатов SHALL быть поле поиска. Ввод MUST сразу фильтровать список по вхождению подстроки в название чата без учёта регистра; группы по дате без подходящих чатов скрываются. Если ничего не найдено, список MUST показывать «Ничего не найдено». Очистка поля MUST возвращать полный список. Поиск одинаков в обоих приложениях.

#### Scenario: Фильтр по названию
- **WHEN** пользователь вводит «mba» в поиск, а в списке есть чаты «Цены на MBA» и «Тест»
- **THEN** в списке остаётся только «Цены на MBA»

#### Scenario: Ничего не найдено
- **WHEN** ни одно название не содержит введённую строку
- **THEN** список показывает «Ничего не найдено», очистка поля возвращает все чаты

## MODIFIED Requirements

### Requirement: Адаптация к ширине панели
Интерфейс SHALL подстраиваться под режим раскладки. В мобильном режиме (панель уже 640 px) MUST показываться либо чат, либо список чатов: из чата к списку ведёт кнопка в верхней панели, выбор чата в списке открывает чат. В планшетном режиме (панель 640 px и шире) и в `control-center` список чатов и активный чат MUST показываться одновременно, а список можно скрыть кнопкой.

#### Scenario: Узкая панель
- **WHEN** ширина панели менее 640 px
- **THEN** отображается либо чат, либо список, переход к списку — кнопкой в верхней панели чата

#### Scenario: Широкая панель
- **WHEN** пользователь растягивает панель до 640 px и более
- **THEN** слева виден список чатов, справа — активный чат; выбор чата в списке сразу открывает его справа

#### Scenario: Изменение ширины
- **WHEN** пользователь меняет ширину панели через порог 640 px
- **THEN** активный чат, история и введённый черновик сохраняются
