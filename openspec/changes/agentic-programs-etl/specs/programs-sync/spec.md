## Purpose

Определить запуск, повторы и наблюдаемость синхронизации каталога, где единицей работы служит группа связанных источников.

## ADDED Requirements

### Requirement: Изменения листов проверяются каждый час
Система SHALL каждый час сравнивать содержимое каждого наблюдаемого листа с его последней успешно обработанной версией.

#### Scenario: Лист не изменился
- **WHEN** отпечаток листа совпадает с отпечатком его последней успешной обработки
- **THEN** система не ставит из-за этого листа новый запуск в очередь

#### Scenario: Лист изменился
- **WHEN** отпечаток листа отличается от отпечатка его последней успешной обработки
- **THEN** система ставит в очередь затронутую группу и передаёт в запуск идентификатор изменённого листа и его новый отпечаток

### Requirement: Неуспешная обработка не поглощает изменение
Система SHALL считать новый отпечаток листа успешно обработанным только после успешного завершения группового запуска.

#### Scenario: Запуск для изменённого листа завершился ошибкой
- **WHEN** групповой запуск не завершился успешно
- **THEN** при следующей часовой проверке лист всё ещё считается изменённым

### Requirement: Синхронизация запускается для группы
Система SHALL создавать отдельный запуск синхронизации для каждой выбранной группы связанных источников.

#### Scenario: Плановый запуск нескольких групп
- **WHEN** планировщик выбирает несколько групп для синхронизации
- **THEN** система создаёт самостоятельный запуск для каждой группы

### Requirement: Неудачный групповой запуск можно повторить
Система SHALL позволять повторно запустить синхронизацию для той же группы после ошибки.

#### Scenario: Повтор после ошибки агента
- **WHEN** групповой запуск завершился ошибкой и для группы запрошен повтор
- **THEN** система создаёт новый запуск для той же группы и сохраняет связь с предыдущей попыткой

### Requirement: Состояние группового запуска наблюдаемо
Система SHALL делать доступными идентификатор группы, идентификатор запуска, время начала и завершения, текущий статус и причину ошибки.

#### Scenario: Групповой запуск завершился ошибкой
- **WHEN** синхронизация группы завершается ошибкой
- **THEN** статус запуска отражает ошибку и указывает её причину вместе с идентификаторами группы и запуска
