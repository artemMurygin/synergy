## Purpose

Определить чтение Google Sheets как группы связанных источников, из которых агент сам запрашивает нужные диапазоны.

## ADDED Requirements

### Requirement: Источники читаются по определению группы
Система SHALL формировать вход агента из списка таблиц и листов, указанных в определении выбранной группы.

#### Scenario: Группа содержит листы из разных таблиц
- **WHEN** определение группы ссылается на несколько листов из разных Google-таблиц
- **THEN** каждая пара `spreadsheet_id` и `sheet_id` доступна агенту в одном групповом запуске

### Requirement: Агент читает выбранные диапазоны
Система SHALL позволять агенту запрашивать выбранные им диапазоны листа и возвращать форматированные значения вместе с исходными номерами строк.

#### Scenario: Агент запрашивает фрагмент листа
- **WHEN** агент запрашивает диапазон конкретного листа из назначенной группы
- **THEN** система возвращает ячейки диапазона и номера их строк в исходном листе

### Requirement: Недоступный источник завершает запуск ошибкой
Система SHALL завершать групповой запуск ошибкой, если агент не может прочитать запрошенный им источник.

#### Scenario: Ошибка чтения Google Sheets
- **WHEN** Google Sheets возвращает ошибку для запрошенного агентом листа или диапазона
- **THEN** групповой запуск завершается с ошибкой, содержащей идентификатор источника
