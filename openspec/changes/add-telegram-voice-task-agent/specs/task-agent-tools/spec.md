## MODIFIED Requirements

### Requirement: Создание задачи агентом
Агент SHALL уметь создавать задачу по просьбе пользователя с теми же полями и ограничениями, что и обычное создание: название (обязательно), описание, срок, ответственный, наблюдатели. Если название не названо, агент MUST спросить его и MUST NOT придумывать значения. Необязательные поля, которые пользователь не назвал, агент MUST один раз предложить заполнить одним сообщением, и пользователь MUST иметь возможность их пропустить. Перед созданием агент MUST показать пользователю карточку задачи со всеми заполненными полями (ответственный и наблюдатели — по логину, срок — конкретной датой и временем) и MUST создавать задачу только после явного подтверждения в ответ на эту карточку. Ответ с правкой MUST приводить к исправленной карточке и новому запросу подтверждения, отказ MUST отменять создание. После создания агент MUST сообщить результат: создана задача или нет и почему. Правила действуют во всех профилях, где доступна работа с задачами.

#### Scenario: Создание с подтверждением
- **WHEN** пользователь называет заголовок, ответственного и срок, агент показывает карточку, и пользователь отвечает «да»
- **THEN** создаётся одна задача с этими полями, а агент сообщает её заголовок и ответственного

#### Scenario: Без подтверждения задача не создаётся
- **WHEN** агент показал карточку, а пользователь ещё не ответил или ответил на другую тему
- **THEN** задача не создана

#### Scenario: Правка карточки
- **WHEN** агент показал карточку, а пользователь ответил «нет, срок в понедельник»
- **THEN** задача не создаётся, агент показывает карточку с новым сроком и снова ждёт подтверждения

#### Scenario: Отмена
- **WHEN** агент показал карточку, а пользователь ответил «отмена»
- **THEN** задача не создаётся, и агент подтверждает отмену

#### Scenario: Не хватает данных
- **WHEN** пользователь просит «поставь задачу» без заголовка
- **THEN** агент спрашивает заголовок и не показывает карточку и не создаёт задачу, пока не получит его

#### Scenario: Необязательные поля
- **WHEN** пользователь назвал только заголовок
- **THEN** агент одним сообщением предлагает указать срок, ответственного, наблюдателей и описание или пропустить их, а после ответа показывает карточку

#### Scenario: Повторное подтверждение
- **WHEN** задача уже создана по карточке, и пользователь ещё раз пишет «да»
- **THEN** вторая такая же задача не создаётся

#### Scenario: Ошибка создания
- **WHEN** создание задачи отклонено по правилам (например, некорректный срок)
- **THEN** агент объясняет причину и не сообщает, что задача создана

## ADDED Requirements

### Requirement: Относительные даты
Агент задач SHALL знать текущие дату и время в часовом поясе Москвы и переводить относительные сроки («сегодня», «завтра», «до пятницы», «через неделю») в конкретную дату. Если время не названо, срок MUST ставиться на 18:00 по Москве. В карточке срок MUST показываться конкретной датой и временем.

#### Scenario: Срок «до пятницы»
- **WHEN** в среду пользователь просит поставить задачу «до пятницы»
- **THEN** в карточке указан срок — ближайшая пятница, 18:00 по Москве
