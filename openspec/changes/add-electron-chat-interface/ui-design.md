# UI Design: add-electron-chat-interface

## Источник дизайна
- **.pen файл**: `design/synergy-design-kit.pen` (единственный .pen в репозитории; в шаблоне указано `sallary-first-iteration.pen`, такого файла нет).
- **UI Kit**: фрейм `k9JASi` («4. Synergy UI Kit») в этом же файле (в шаблоне указан `uDEum`, такого фрейма нет). Мастер-компоненты: `Button / Master` (`pbEvR`), `Field / Master` (`b7hxv`), `Run Notice / Master` (`HfVTG`).
- **Референс**: макеты расширения «09 · Manager Helper · Чаты» (`KBBna`) и «10 · Manager Helper · Чат на AG-UI» (`GHRO6`). Поведение и паттерны (элемент списка, пузыри сообщений, композер, уведомления) взяты оттуда, раскладка сделана заново под окно 1440.
- **Токены**: `$ink`, `$ink-60`, `$ink-40`, `$surface`, `$surface-alt`, `$surface-sunken`, `$border`, `$brand-red`, `$brand-red-soft`, `$font-display` (Onest), `$font-ui` (Raleway), `$r-sm`, `$r-md`, `$r-lg`. Хардкод цветов не использован.

## Новые компоненты UI Kit

Новых reusable-компонентов в UI Kit не создавалось: использованы `Button / Master`, `Field / Master` и `Run Notice / Master`. Элементы списка, пузыри сообщений и скелетоны собраны из фреймов по образцу макетов расширения (в UI Kit для них отдельных мастеров нет, как и в референсе).

## Отклонения от architecture.md

1. **Удаление чата без модального окна.** В `architecture.md` и `design.md` предусмотрены `DeleteThreadDialog` и примитив `Dialog`. В референсе расширения подтверждение удаления встроено в строку списка («Удалить чат вместе с историей? Это необратимо.» с кнопками «Отмена» и «Удалить»), и десктопный макет повторяет этот паттерн. Следствие: `DeleteThreadDialog` заменяется состоянием элемента `ChatListItem` (режим `confirmDelete`), примитив `Dialog` в `components/ui` не нужен. Для чата с идущим ответом текст подтверждения дополняется предупреждением. Согласовано с пользователем; `architecture.md` и `design.md` обновлены.
2. **Имя файла и фрейма UI Kit** отличаются от указанных в шаблоне (см. «Источник дизайна»).
3. **Заголовок диалога** содержит только название чата и время последней активности: кнопки «Новый чат» и «Настройки» из расширения в десктопе не нужны (новый чат создаётся в боковой панели, настроек нет по `design.md`).
4. **Skeleton**: отдельный компонент `components/ui/skeleton` остаётся нужным (скелетон-строки списка), `Input` нужен для инлайн-переименования.
