## MODIFIED Requirements

### Requirement: Состав профиля «приложение»
Агент профиля «приложение» SHALL самостоятельно решать по содержанию вопроса, чем отвечать:
- вопросы о ценовой политике он MUST передавать специалисту по ценовой политике;
- вопросы о задачах — специалисту по задачам;
- записи встреч, расшифровки, имена спикеров и задачи из встречи — специалисту по встречам.

Специалист по ценовой политике MUST получать только текст поручения. Специалист по задачам и специалист по встречам MUST получать также историю текущего чата, включая сведения о вложениях и сообщения системы. Когда пользователь согласился поставить задачи из встречи, список задач MUST передаваться специалисту по задачам вместе с основаниями из расшифровки. Один чат MUST допускать вопросы всех видов подряд.

#### Scenario: Вопрос о ценах
- **WHEN** пользователь спрашивает о ценовой политике в чате
- **THEN** ответ формирует специалист по ценовой политике, а пользователь видит один общий ответ в чате

#### Scenario: Вопрос о задачах
- **WHEN** пользователь просит поставить задачу в чате
- **THEN** запрос выполняет специалист по задачам с учётом предыдущих сообщений чата

#### Scenario: Запись встречи
- **WHEN** пользователь отправляет в чат запись встречи
- **THEN** запрос выполняет специалист по встречам

#### Scenario: От встречи к постановке задач
- **WHEN** специалист по встречам выдал список задач, и пользователь согласился создать их
- **THEN** согласование и создание задач выполняет специалист по задачам, получив этот список

#### Scenario: Смена темы в одном чате
- **WHEN** пользователь сначала спрашивает о ценах, а затем в том же чате просит найти свои задачи
- **THEN** оба вопроса получают ответ специалиста по своей теме, а история чата содержит оба обмена
