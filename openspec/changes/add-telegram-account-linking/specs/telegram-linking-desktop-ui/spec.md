## Purpose

Раздел «Telegram» в Electron-приложении control-center: подключение Telegram-аккаунта по ссылке, просмотр статуса привязки, переключатель уведомлений и отвязка поверх REST API бэкенда.

## ADDED Requirements

### Requirement: Точка входа в меню аккаунта
Меню аккаунта на nav rail SHALL содержать пункт «Telegram» с текущим состоянием: «Не подключён» или username привязанного аккаунта. Пункт открывает раздел Telegram. Если сервер сообщает, что бот не настроен, пункт MUST не показываться.

#### Scenario: Привязки нет
- **WHEN** пользователь без привязки открывает меню аккаунта
- **THEN** он видит пункт «Telegram» с подписью «Не подключён»

#### Scenario: Бот не настроен
- **WHEN** статус привязки сообщает, что бот на сервере недоступен
- **THEN** пункта «Telegram» в меню нет

### Requirement: Подключение аккаунта
В разделе Telegram пользователь без привязки SHALL видеть кнопку «Подключить». По нажатию приложение MUST выпустить ссылку, открыть её во внешнем браузере или в Telegram средствами ОС и перейти в состояние ожидания с кнопкой «Открыть ссылку ещё раз» и отменой. Пока раздел в состоянии ожидания, приложение MUST периодически запрашивать статус привязки и, когда привязка появится, показать подключённое состояние без действий пользователя. Когда срок ссылки истекает, ожидание MUST завершаться с предложением выпустить новую ссылку. Ошибку выпуска ссылки MUST показывать с кнопкой повтора.

#### Scenario: Успешное подключение
- **WHEN** пользователь нажимает «Подключить», в открывшемся Telegram нажимает Start и возвращается в приложение
- **THEN** раздел показывает подключённое состояние с username аккаунта, а пункт меню показывает этот username

#### Scenario: Ссылка истекла
- **WHEN** пользователь не завершил привязку до истечения срока ссылки
- **THEN** ожидание прекращается, и показывается сообщение «Ссылка устарела» с кнопкой «Получить новую»

### Requirement: Управление привязкой
Пользователь с привязкой SHALL видеть в разделе username аккаунта, время привязки, переключатель «Уведомления в Telegram» и кнопку «Отключить». Переключатель MUST сразу отражать новое значение и откатываться с сообщением об ошибке, если сервер не принял изменение. Отключение MUST запрашивать подтверждение, а после успеха раздел MUST возвращаться в состояние «Не подключён».

#### Scenario: Выключение уведомлений
- **WHEN** пользователь выключает переключатель уведомлений
- **THEN** переключатель сразу показывает «выключено», а после ответа сервера значение сохраняется

#### Scenario: Ошибка переключения
- **WHEN** сервер отвечает ошибкой на изменение переключателя
- **THEN** переключатель возвращается в прежнее положение, и показывается сообщение об ошибке

#### Scenario: Отключение
- **WHEN** пользователь нажимает «Отключить» и подтверждает
- **THEN** раздел показывает состояние «Не подключён» с кнопкой «Подключить»
