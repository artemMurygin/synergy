## Purpose

Хранит фрагменты текстового описания программ с векторами и метаданными, чтобы агент подбора мог искать программы по смыслу и точным словам, сочетая это с фильтрами по каталогу.

## ADDED Requirements

### Requirement: Фрагменты содержимого
Система SHALL хранить фрагменты текста программы с типом раздела, самим текстом, ссылкой на программу и организацию, уровнем и хэшем содержимого. Тип раздела MUST принадлежать набору (о программе, дисциплины, карьера, цель курса, УТП, FAQ, люди, кейсы, практика). Фрагмент MUST быть привязан к программе.

#### Scenario: Фрагмент без программы
- **WHEN** сохраняется фрагмент без привязки к программе
- **THEN** операция отклоняется нарушением ограничения

#### Scenario: Недопустимый тип раздела
- **WHEN** сохраняется фрагмент с типом вне допустимого набора
- **THEN** операция отклоняется нарушением ограничения

### Requirement: Векторное представление
Система SHALL хранить для фрагмента вектор фиксированной размерности и поддерживать поиск ближайших фрагментов по косинусному расстоянию. Фрагмент MAY существовать без вектора, пока вектор не рассчитан; такие фрагменты MUST NOT попадать в результаты векторного поиска. Вектор другой размерности MUST быть отклонён.

#### Scenario: Ближайшие фрагменты
- **WHEN** выполняется поиск по вектору запроса с лимитом 10
- **THEN** возвращаются не более 10 фрагментов, упорядоченных по возрастанию расстояния

#### Scenario: Фрагмент без вектора
- **WHEN** фрагмент сохранён, но вектор для него ещё не рассчитан
- **THEN** он отсутствует в результатах векторного поиска и присутствует в выборке фрагментов без вектора

#### Scenario: Вектор неверной размерности
- **WHEN** сохраняется вектор размерности, отличной от заданной
- **THEN** операция отклоняется

### Requirement: Фильтрация вместе с поиском
Система SHALL позволять ограничивать как векторный, так и полнотекстовый поиск по организации, уровню, типу раздела и конкретным программам одним запросом, чтобы результаты соответствовали заданным условиям каталога.

#### Scenario: Поиск в пределах уровня
- **WHEN** выполняется векторный поиск с ограничением «уровень СПО»
- **THEN** в результатах нет фрагментов программ другого уровня

#### Scenario: Поиск среди выбранных программ
- **WHEN** поиск ограничен списком идентификаторов программ
- **THEN** результаты принадлежат только этим программам

### Requirement: Полнотекстовый поиск
Система SHALL поддерживать полнотекстовый поиск на русском языке по названиям, кодам направлений, квалификациям и тексту фрагментов, включая точное совпадение кода направления.

#### Scenario: Поиск по коду направления
- **WHEN** выполняется поиск по строке «44.02.02»
- **THEN** возвращается программа с этим кодом направления

#### Scenario: Поиск по словоформе
- **WHEN** выполняется поиск по слову «фельдшеры»
- **THEN** находятся программы и фрагменты со словом «фельдшер»

### Requirement: Пересчёт только изменившихся фрагментов
Система SHALL хранить хэш содержимого фрагмента так, чтобы можно было определить, изменился ли текст, и пересчитывать вектор только для изменившихся фрагментов. Изменение текста MUST сбрасывать устаревший вектор.

#### Scenario: Текст не менялся
- **WHEN** фрагмент записывается повторно с тем же текстом
- **THEN** хэш не меняется, и вектор сохраняется

#### Scenario: Текст изменился
- **WHEN** фрагмент записывается с изменённым текстом
- **THEN** хэш обновляется, а прежний вектор сбрасывается до нового расчёта

### Requirement: Каскадная очистка
Удаление программы MUST каскадно удалять все её фрагменты.

#### Scenario: Удаление программы
- **WHEN** программа удаляется
- **THEN** все её фрагменты исчезают из векторного и полнотекстового поиска
