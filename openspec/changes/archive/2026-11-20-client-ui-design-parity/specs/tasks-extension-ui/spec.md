## ADDED Requirements

### Requirement: Группы по сроку в компактном списке
В планшетном и мобильном режимах список задач, отсортированный по дедлайну, SHALL делиться на группы с подписями «Просрочено», «На этой неделе», «Позже», «Без срока». Пустые группы не показываются. При другой сортировке группы не показываются. Кнопка подгрузки следующей страницы называется «Показать ещё», без счётчика.

#### Scenario: Группы по сроку
- **WHEN** у пользователя есть просроченная задача, задача на завтра и задача без дедлайна
- **THEN** список показывает группы «Просрочено», «На этой неделе» и «Без срока», каждая со своей задачей

#### Scenario: Сортировка не по сроку
- **WHEN** пользователь выбирает сортировку по дате изменения
- **THEN** список показывается без подписей групп

### Requirement: Поиск в мобильном режиме
В мобильном режиме поиск задач SHALL открываться отдельной строкой поиска поверх шапки списка: кнопка «Назад», поле поиска и «Очистить». «Назад» MUST закрывать строку поиска и очищать запрос. «Очистить» MUST очищать поле, оставляя строку открытой.

#### Scenario: Открытие поиска
- **WHEN** пользователь в мобильном режиме нажимает поиск в шапке списка
- **THEN** открывается строка поиска с фокусом в поле, кнопками «Назад» и «Очистить»

#### Scenario: Закрытие поиска
- **WHEN** пользователь нажимает «Назад» в строке поиска
- **THEN** строка поиска закрыта, запрос очищен, список без поиска

### Requirement: Создание и детали в планшетном режиме
В планшетном режиме создание задачи SHALL открываться диалогом по центру панели с полной формой. Детали выбранной задачи в правом столбце MUST иметь кнопку «Закрыть». Она снимает выбор и возвращает подсказку «Выберите задачу».

#### Scenario: Создание на планшете
- **WHEN** пользователь в планшетном режиме нажимает «Создать задачу»
- **THEN** открывается диалог по центру панели

#### Scenario: Закрытие деталей
- **WHEN** пользователь нажимает «Закрыть» в деталях задачи в планшетном режиме
- **THEN** выбор снят, справа подсказка «Выберите задачу»

## MODIFIED Requirements

### Requirement: Быстрое создание задачи
Пользователь SHALL создавать задачу из панели одним полем названия с необязательными дедлайном и ответственным (по умолчанию — текущий пользователь). В мобильном режиме быстрое создание открывается нижней шторкой с захватом и подсказкой «Enter — создать». В шторке есть:
- чипы дедлайна «Сегодня», «Завтра», «Дата…», «Без срока»;
- чипы ответственного «Я · <логин>» и «Выбрать…»;
- раскрывающийся блок «Описание и наблюдатели».

«Дата…» и «Выбрать…» MUST открывать вложенные шторки «Дедлайн» и «Ответственный» с кнопкой «Назад», которая возвращает к форме без потери введённого. Расширенные поля MUST быть доступны в раскрывающейся части формы. Отправка блокируется при пустом названии и во время запроса.

#### Scenario: Создание одним названием
- **WHEN** пользователь вводит название и подтверждает Enter
- **THEN** задача создаётся с ответственным «я», появляется в списке

#### Scenario: Дедлайн чипом
- **WHEN** пользователь в мобильной шторке вводит название, выбирает чип «Завтра» и нажимает Enter
- **THEN** задача создаётся с дедлайном на завтра

#### Scenario: Вложенная шторка
- **WHEN** пользователь нажимает «Выбрать…», а затем «Назад» во вложенной шторке «Ответственный»
- **THEN** форма быстрого создания показана с прежним названием и выбранным дедлайном

#### Scenario: Ошибка сервера
- **WHEN** сервер отклонил создание
- **THEN** введённый текст сохраняется, показана ошибка
