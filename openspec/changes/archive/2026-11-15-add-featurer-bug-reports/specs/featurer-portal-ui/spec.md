## MODIFIED Requirements

### Requirement: Видимость разделов по роли
Портал SHALL показывать разделы «Новая идея», «Мои заявки», «Каталог», «Роадмап» и «Поддержка» любому вошедшему сотруднику. Разделы «Очередь», «Решение по заявке», «Навыки», «Баги» и «Архив» MUST показываться только пользователю с ролью `developer` по данным профиля. Разделы «Сотрудники» и «Отделы» MUST показываться только пользователю с ролью `admin` (`featurer-admin-ui`). Роли независимы: пользователь с обеими ролями видит оба набора разделов, а `admin` без `developer` не видит разделов разработчика. Прямой переход пользователя без нужной роли по адресу закрытого раздела MUST не показывать его данных и MUST вести на «Мои заявки». Скрытие разделов не заменяет проверку роли на сервере.

#### Scenario: Меню сотрудника
- **WHEN** входит пользователь без ролей
- **THEN** в навигации «Новая идея», «Мои заявки», «Каталог», «Роадмап» и «Поддержка»

#### Scenario: Меню разработчика
- **WHEN** входит пользователь с ролью `developer`
- **THEN** в навигации также есть «Очередь», «Навыки», «Баги» и «Архив»

#### Scenario: Меню администратора
- **WHEN** входит пользователь с ролью `admin` без роли `developer`
- **THEN** в навигации «Новая идея», «Мои заявки», «Каталог», «Роадмап», «Поддержка», «Сотрудники» и «Отделы», а «Очереди», «Навыков», «Багов» и «Архива» нет

#### Scenario: Обе роли
- **WHEN** входит пользователь с ролями `developer` и `admin`
- **THEN** в навигации есть разделы обеих ролей

#### Scenario: Прямой адрес раздела разработчика
- **WHEN** сотрудник без роли открывает адрес очереди, очереди багов или архива вручную
- **THEN** портал показывает «Мои заявки», данные раздела не запрашиваются

#### Scenario: Прямой адрес раздела администратора
- **WHEN** пользователь без роли `admin` открывает адрес списка сотрудников вручную
- **THEN** портал показывает «Мои заявки», данные сотрудников не запрашиваются
