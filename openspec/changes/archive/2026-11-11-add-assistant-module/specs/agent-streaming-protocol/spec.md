## MODIFIED Requirements

### Requirement: Запуск агента в чате
Система SHALL принимать запуск агента для существующего чата (thread) его владельца: идентификатор чата и новое сообщение пользователя. Агент MUST действовать от имени аутентифицированного пользователя и быть собран по профилю клиента, из которого пришёл запрос. В ответ система MUST отдавать поток событий в формате протокола AG-UI, начинающийся с события начала запуска и заканчивающийся событием завершения или ошибки. Контекст агента MUST определяться только историей этого чата.

#### Scenario: Успешный запуск
- **WHEN** клиент отправляет вопрос в существующий чат
- **THEN** система открывает поток событий, который начинается с события начала запуска и завершается событием завершения запуска

#### Scenario: Чат не найден
- **WHEN** клиент запускает агента с идентификатором чата, которого нет в системе или который принадлежит другому пользователю
- **THEN** система отвечает ошибкой «не найдено» до начала потока, вопрос агенту не передаётся и ничего не сохраняется

#### Scenario: Некорректный вопрос
- **WHEN** клиент отправляет пустое сообщение или сообщение длиннее допустимого лимита
- **THEN** система отклоняет запуск с ошибкой валидации и ничего не сохраняет

#### Scenario: Запуск по профилю клиента
- **WHEN** запуск приходит из приложения
- **THEN** агент собирается по профилю «приложение», и формат потока событий не отличается от прежнего
