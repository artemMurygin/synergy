## Purpose

Даёт LLM-агенту набор инструментов для чтения, фильтрации и агрегации данных о звонках VocalAI, синхронизированных capability `vocal-ai-call-sync` в локальное хранилище, без прямых обращений агента к внешнему VocalAI API.

## ADDED Requirements

### Requirement: Список звонков с фильтрацией из локального хранилища
Система SHALL предоставлять инструмент, возвращающий список звонков из локального хранилища с фильтрацией по проекту, диапазону дат звонка, менеджеру (оператору), диапазону общей оценки, тегу и метрике чек-листа, без обращения к внешнему VocalAI API.

#### Scenario: Фильтрация по менеджеру и периоду
- **WHEN** агент запрашивает список звонков с указанием менеджера и диапазона дат
- **THEN** инструмент возвращает из локального хранилища только звонки этого менеджера, дата которых входит в указанный диапазон

#### Scenario: Пустой результат
- **WHEN** фильтрам не соответствует ни один сохранённый звонок
- **THEN** инструмент возвращает пустой список без ошибки

### Requirement: Детали звонка без транскрипции
Система SHALL предоставлять инструмент, возвращающий по идентификатору звонка его метрики чек-листа, присвоенные теги, AI-саммари и общую оценку из локального хранилища, без текста транскрипции.

#### Scenario: Запрошены детали существующего звонка
- **WHEN** агент запрашивает детали звонка по известному идентификатору
- **THEN** инструмент возвращает сохранённые метрики, теги, саммари и общую оценку этого звонка

#### Scenario: Запрошены детали несуществующего звонка
- **WHEN** агент запрашивает детали звонка с идентификатором, которого нет в локальном хранилище
- **THEN** инструмент возвращает явную ошибку "звонок не найден" без обращения к внешнему API

### Requirement: Транскрипция звонка с ленивой подгрузкой
Система SHALL предоставлять инструмент, возвращающий полный текст транскрипции звонка по его идентификатору; если транскрипция ещё не сохранена локально, инструмент SHALL инициировать её ленивую загрузку (согласно capability `vocal-ai-call-sync`) перед возвратом результата.

#### Scenario: Транскрипция уже синхронизирована
- **WHEN** агент запрашивает транскрипцию звонка, которая уже есть в локальном хранилище
- **THEN** инструмент немедленно возвращает реплики транскрипции (спикер, роль, временные метки, текст) без похода во внешний API

#### Scenario: Транскрипция ещё не синхронизирована
- **WHEN** агент запрашивает транскрипцию звонка, для которого она не сохранена локально
- **THEN** инструмент дожидается ленивой загрузки транскрипции и возвращает её, либо возвращает ошибку, если звонок с таким идентификатором не существует

### Requirement: Агрегированная статистика по звонкам
Система SHALL предоставлять инструмент, возвращающий агрегированную статистику (количество звонков, среднюю оценку, долю проблемных звонков) по звонкам, отфильтрованным по тем же критериям, что и список звонков, вычисленную по данным локального хранилища без обращения к внешнему API аналитики.

#### Scenario: Агрегация по менеджеру за период
- **WHEN** агент запрашивает агрегированную статистику с фильтром по менеджеру и периоду
- **THEN** инструмент возвращает количество звонков, среднюю оценку и долю проблемных звонков, посчитанные только по звонкам, соответствующим этому фильтру

### Requirement: Изоляция инструментов агента от внешнего API
Инструменты агента SHALL читать данные исключительно из локального хранилища синхронизации, за исключением явной ленивой загрузки транскрипции; инструменты SHALL NOT инициировать произвольные запросы к внешнему VocalAI API помимо этого случая.

#### Scenario: Инструмент фильтрации не обращается к внешнему API
- **WHEN** агент вызывает инструмент списка или агрегации звонков
- **THEN** выполнение инструмента не производит ни одного HTTP-запроса к VocalAI API
