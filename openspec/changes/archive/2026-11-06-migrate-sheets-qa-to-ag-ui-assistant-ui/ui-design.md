# UI Design: migrate-sheets-qa-to-ag-ui-assistant-ui

## Источник дизайна
- **.pen файл**: `design/synergy-design-kit.pen` (общий файл дизайна репозитория; шаблон ссылался на `sallary-first-iteration.pen` и фрейм `uDEum` из другого проекта, здесь их нет). Новый `.pen` файл не создавался.
- **UI Kit**: фрейм `k9JASi` «4. Synergy UI Kit» в этом же файле. Использованы `Button / Master` (`pbEvR`), `Field / Master` (`b7hxv`), `Chip / Master` (`xFsWD`).
- **Готовый макет чата**: `KBBna` «09 · Manager Helper · Чаты» (активный чат, список, планшетный режим). Он не менялся и остаётся основой; новые состояния скопированы из него.
- Токены: `$brand-red`, `$brand-red-soft`, `$ink`, `$ink-60`, `$ink-80`, `$surface`, `$surface-alt`, `$border`, `$border-strong`, `$success`, `$info`, `$r-md`, `$r-lg`, `$font-ui`, `$font-display`. Хардкодом только `#E3EBFB` (фон информационного уведомления, как у `Alert info` в ките).

## Новые компоненты UI Kit

Сохранены как reusable внутри `k9JASi`, раздел «05 · Молекулы» (`W1oMzb`), строка Row E, панель «Чат агента (AG-UI)» (`y6RhdX`).

| Компонент | Node ID (внутри UI Kit) | Где используется | Почему существующего недостаточно |
|---|---|---|---|
| `Tool Call Row / Master` | `Q9teX` | Строки внутри «Ход работы»: статус (галочка или спиннер), имя инструмента, аргументы | В ките нет компонента строки со статусом выполнения |
| `Tool Trace / Master` | `AHgP8` | Блок «Ход работы» в сообщении агента; свёрнут (`Trace Body` отключён, шеврон `chevron-right`) или раскрыт | Нет сворачиваемого блока с заголовком и списком строк |
| `Run Notice / Master` | `HfVTG` | Ошибка, остановка и идущий запуск (варианты через override: фон, иконка, заголовок, текст, действие) | `Alert` в ките — панель-локальные фреймы шириной под форму, а не reusable-компонент для узкого чата |

Кнопка «Остановить» — не новый компонент: это `Button / Master` (`pbEvR`) с обводкой `$border-strong`, белым фоном, иконкой `square` и без тени.

## Отклонения от architecture.md

- `RunningIndicator` в архитектуре — «индикатор и кнопка Остановить для возврата в идущий запуск». В макете кнопка «Остановить» живёт в композере (заменяет «Спросить») во всех состояниях идущего запуска, а сам индикатор — информационное уведомление в ленте. Состав компонента остаётся прежним, меняется только место кнопки. На спеки это не влияет.
- Уведомление «Ответ остановлен» — новый вариант `Run Notice`, не перечисленный в architecture.md отдельным компонентом; реализуется тем же `ErrorMessage`/`RunningIndicator` или общим компонентом уведомления. Решение о форме компонента — на этапе реализации.

## Замечания по проверке

- Layout проверен скриншотами всех пяти состояний и итогового фрейма `GHRO6`: пустых контейнеров, обрезки и наложений нет.
- Pencil несколько раз возвращал ошибку подключения (`wrong .pen file`), при этом изменения применялись; результат проверен чтением узлов и скриншотами после перезапуска.
