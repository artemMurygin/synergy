## Purpose

Инструкция к агенту в портале Featurer: один markdown-текст на агента, который читает любой сотрудник, а пишет и обновляет разработчик. Сотрудник узнаёт, как пользоваться агентом, не спрашивая разработчика.

## ADDED Requirements

### Requirement: Чтение инструкции агента
Система SHALL возвращать любому вошедшему сотруднику инструкцию неархивного агента: текст в markdown, время последней правки и автора последней правки (идентификатор, логин и полное имя, без ФИО — логин). Если у агента нет инструкции, система MUST отвечать 200 с пустой инструкцией (текст, время и автор пусты). Неизвестный агент, агент в архиве и идентификатор неверного формата MUST отвечаться 404. Запрос без access-токена MUST отвечаться 401. Текст MUST возвращаться без изменений, система MUST NOT преобразовывать markdown.

#### Scenario: Сотрудник читает инструкцию
- **WHEN** сотрудник без ролей запрашивает инструкцию агента Ассистент
- **THEN** система отвечает 200 и возвращает текст, время и автора последней правки

#### Scenario: Инструкции нет
- **WHEN** сотрудник запрашивает инструкцию агента, для которого её не писали
- **THEN** система отвечает 200, текст, время и автор пусты

#### Scenario: Агент в архиве
- **WHEN** сотрудник запрашивает инструкцию архивного агента
- **THEN** система отвечает 404

### Requirement: Правка инструкции разработчиком
Система SHALL позволять пользователю с ролью `developer` сохранить инструкцию неархивного агента целиком: новый текст заменяет прежний. Текст MUST быть не длиннее 50 000 символов, иначе 400 без изменений. Пробелы и пустые строки по краям MUST удаляться, остальной текст MUST сохраняться без изменений, включая HTML-фрагменты, которые система хранит как текст. Если после удаления пробелов текст пустой, инструкция MUST удаляться, и ответ MUST быть пустой инструкцией. При сохранении MUST записываться время и автор правки. Система MUST NOT хранить историю версий. Ответ MUST быть 200 и инструкцией в формате чтения.

Ошибки:
- пользователь без роли `developer` — 403;
- неизвестный агент или некорректный идентификатор — 404;
- агент в архиве — 409;
- запрос без access-токена — 401.

Одновременные сохранения MUST NOT приводить к ошибке: сохраняется последнее.

#### Scenario: Разработчик пишет инструкцию
- **WHEN** разработчик сохраняет инструкцию «## Как начать\n1. Откройте control-center» для агента без инструкции
- **THEN** система отвечает 200, инструкция сохранена с его именем и временем правки

#### Scenario: Правка заменяет текст
- **WHEN** другой разработчик сохраняет новый текст инструкции
- **THEN** чтение возвращает новый текст и имя второго разработчика, прежний текст не хранится

#### Scenario: Пустой текст удаляет инструкцию
- **WHEN** разработчик сохраняет текст из пробелов и переносов строк
- **THEN** система отвечает 200 с пустой инструкцией, чтение тоже возвращает пустую

#### Scenario: Слишком длинный текст
- **WHEN** разработчик сохраняет текст длиннее 50 000 символов
- **THEN** система отвечает 400, прежняя инструкция не меняется

#### Scenario: Сотрудник без роли
- **WHEN** сотрудник без роли `developer` пытается сохранить инструкцию
- **THEN** система отвечает 403

#### Scenario: Архивный агент
- **WHEN** разработчик сохраняет инструкцию агента в архиве
- **THEN** система отвечает 409, инструкция не меняется

### Requirement: Инструкция при архивации агента
Система SHALL сохранять инструкцию агента при его архивации и MUST возвращать её без изменений после восстановления агента. Архивация и восстановление MUST NOT менять время и автора последней правки.

#### Scenario: Восстановление агента
- **WHEN** агент с инструкцией архивирован, затем восстановлен
- **THEN** чтение инструкции возвращает прежний текст, время и автора
