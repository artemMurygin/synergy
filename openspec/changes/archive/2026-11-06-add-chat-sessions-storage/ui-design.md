# UI Design: add-chat-sessions-storage

## Источник дизайна
- **.pen файл**: `design/synergy-design-kit.pen` (в репозитории нет `sallary-first-iteration.pen`; активный дизайн-файл проекта — Synergy UI Kit)
- **UI Kit**: фрейм `k9JASi` «4. Synergy UI Kit» в этом же файле. Мастер-компоненты: `pbEvR` Button, `f4P4A` Badge, `xFsWD` Chip, `e0G7e` Avatar, `b7hxv` Field, `yETBr` Stat, `cLDfH` Program Card, `BpW5r` Faculty Row. Варианты кнопок (Primary / Secondary / Outline / Ghost) — это `ref` на `pbEvR` с переопределением `fill`/`stroke`/`effect`; те же приёмы использованы здесь.
- **Контейнер с макетами**: фрейм `KBBna` «09 · Manager Helper · Чаты» (ниже секции «08 · Правила»).

Брейкпоинты: узкая панель — 380×720 (по умолчанию), растянутая панель («планшет») — 860×720. Вместо 1440/390 из шаблона схемы, потому что это side panel расширения Chrome; мобильной версии нет. Адаптив по ширине панели: **< 640 px** — один режим за раз («Чат» или «Список»); **≥ 640 px** — две колонки: список чатов слева (300 px) и чат справа.

Page из architecture.md — одна: Side panel (`sidepanel/App.tsx`) с двумя режимами: «Чат» и «Список чатов». Каждый режим показан отдельными артбордами.

| Page (из architecture.md) | Имя фрейма в .pen | Node ID | Breakpoints | Переиспользованные компоненты UI Kit | Статус |

| Side panel · режим «Список чатов» (`ChatSessionList`, `ChatSessionItem`) | List · Default | `k2xZXW` | 380 | Button `pbEvR` («Новый чат», иконки действий) | ready |

### Планшет (панель растянута, ≥ 640 px)
| Экран | Имя фрейма в .pen | Node ID | Что изменилось относительно узкой панели |
|---|---|---|---|

Заметные детали, которые нужны исполнителю:
- **ChatHeader** (`G4OrgD` в Chat · Active): кнопка «к списку» (`messages-square`) → название чата (Onest 16/600) → «Новый чат» (`square-pen`) → «Настройки» (`settings`). Старая кнопка «Очистить» заменена на «Новый чат».
- **Активный чат** в списке выделен `$brand-red-soft`; удаляемый — иконка `trash-2` красная и блок подтверждения с кнопками «Отмена» (Secondary) / «Удалить» (Primary).
- **Сообщение пользователя** — `$brand-red`, агента — `$surface-alt`; под ответом агента строка трассировки (`$ink-60`, 12 px).
- **Форма «Быстрый подбор»** (по референсу `fxiju`, текущий вид панели) адаптирована под чаты и показана на макетах:
  - *Новый/пустой чат* (`L0EhQB`): форма раскрыта над полем ввода; поля («Что ищем», «Уровень», «База клиента», «Направление (до 3)») прокручиваются, кнопка «Начать подбор» закреплена внизу формы и не уходит при скролле.
  - *Чат с ответами* (`s7f4n`): форма свёрнута в строку «Быстрый подбор ›», ниже — «Следующие шаги» (чипы «Подробнее по 1-й», «Вступительные», «Показать ещё», «Новый подбор»); «Новый подбор» раскрывает форму.
  - *Агент отвечает* (`y4MBK5`): свёрнутая форма и шаги приглушены (disabled).
  - Опции формы — Chip `xFsWD` (выбранный: `$brand-red-soft` + рамка `$brand-red`), «Начать подбор» — Button `pbEvR`. Синий акцент текущей панели заменён на фирменный красный из UI Kit.
  - Состояние формы относится к конкретному чату и сбрасывается при переключении; название нового чата формируется из параметров формы (например, «Бакалавриат · Медицина»). Вариант формы для сегмента «Курсы и ДПО» (тема, «Своя тема», количество) отдельным артбордом не рисовался: меняется только набор полей.

## Отклонения от architecture.md
- Файл и фрейм UI Kit другие, чем указано в шаблоне схемы (`synergy-design-kit.pen` / `k9JASi` вместо `sallary-first-iteration.pen` / `uDEum`): по указанию пользователя использован UI Kit, который есть в открытом файле.
- Размер экранов 380×720 вместо 1440/390 (side panel расширения).
- В `ChatHeader` дополнительно оставлена кнопка «Настройки» (есть в текущей панели).
- Форма быстрого подбора изменила в `architecture.md` описание существующих `QuickSearchForm` и `NextSteps` и добавила требование в спек `chat-session-switcher`.
- Лишних экранов и сущностей сверх architecture.md нет; состояния «Список · загрузка» и «Чат · пустой» следуют из спеков.
