## Purpose

Документы Word, которые получает пользователь по встрече: расшифровка с именами спикеров и список задач. Описывает их содержание, формат и хранение.

## ADDED Requirements

### Requirement: Документ расшифровки
Система SHALL формировать документ расшифровки в формате `.docx`. В документе:
- заголовок с именем записи;
- дата загрузки, длительность в формате `чч:мм:сс`, список участников (имена или метки спикеров);
- реплики в порядке времени, каждая в формате «[чч:мм:сс] Имя: текст».

Время отсчитывается от начала записи. Для спикера с назначенным именем MUST использоваться имя, без имени — метка (`Спикер 1`). Подряд идущие реплики одного спикера (с учётом одинаковых имён) MUST объединяться в одну реплику с временем первой. Текст реплик MUST совпадать с расшифровкой.

#### Scenario: Расшифровка с именами
- **WHEN** спикеру 1 назначено имя «Анна», спикеру 2 имя не назначено
- **THEN** реплики первого подписаны «Анна», второго — «Спикер 2», в шапке участники «Анна, Спикер 2»

#### Scenario: Склейка по одинаковому имени
- **WHEN** спикерам 2 и 4 назначено имя «Олег», и их реплики идут подряд
- **THEN** в документе это одна реплика «Олег» с временем первой из них

#### Scenario: Документ открывается в Word
- **WHEN** пользователь открывает документ в Microsoft Word или LibreOffice
- **THEN** документ открывается без предупреждений о повреждении, кириллица отображается корректно

### Requirement: Документ задач встречи
Система SHALL формировать документ задач в формате `.docx`: заголовок с именем записи и датой встречи, затем таблица с колонками «№», «Задача», «Описание», «Исполнитель», «Постановщик», «Срок», «Основание». В колонке «Основание» указываются цитата и таймкод. Пустые значения MUST отображаться прочерком.

#### Scenario: Задача без срока
- **WHEN** у задачи не определён срок
- **THEN** в колонке «Срок» стоит прочерк

### Requirement: Документ поставленных задач
После создания задач из списка, полученного из встречи, система SHALL формировать документ `.docx` с итогом постановки. В документе:
- заголовок с именем записи и датой постановки;
- таблица с колонками «№», «Задача», «Исполнитель», «Постановщик», «Срок», «Результат».

В колонке «Результат» указывается «Создана» или «Не создана: <причина>». Исполнитель и постановщик MUST показываться по именам пользователей системы, а не по упоминаниям из речи. Задачи, исключённые пользователем до подтверждения, MUST NOT попадать в документ. Если ни одна задача не была создана, документ MUST всё равно формироваться с причинами.

#### Scenario: Частично созданный список
- **WHEN** из трёх задач созданы две, а третья отклонена из-за отключённого исполнителя
- **THEN** в документе три строки: две с результатом «Создана», одна с результатом «Не создана» и причиной

#### Scenario: Исключённая задача
- **WHEN** пользователь исключил вторую задачу до подтверждения
- **THEN** в документе её нет

### Requirement: Хранение документов
Каждый документ SHALL сохраняться как файл пользователя вида `document` с обычным сроком хранения документов. Имя файла MUST строиться по шаблону «Расшифровка — <имя записи без расширения>.docx», «Задачи — <имя записи без расширения>.docx» или «Поставленные задачи — <имя записи без расширения>.docx». Каждое изменение имён спикеров MUST создавать новый документ, а не менять ранее выданный. Расшифровка MUST оставаться источником данных: документ можно получить заново, даже если запись или прошлые документы уже удалены.

#### Scenario: Документ после смены имён
- **WHEN** пользователь дважды поменял имена спикеров
- **THEN** в чате три документа расшифровки, каждый с именами на момент выдачи

#### Scenario: Запись удалена по сроку
- **WHEN** запись удалена через день после расшифровки, а пользователь назначает имена спикерам через неделю
- **THEN** агент выдаёт новый документ расшифровки с именами

### Requirement: Приватность документов в логах
Система SHALL NOT писать в логи текст документов, имена спикеров и тексты задач. В лог MUST попадать идентификатор расшифровки, вид документа, число реплик или задач и размер файла.

#### Scenario: Формирование документа
- **WHEN** сформирован документ расшифровки
- **THEN** в логе есть идентификатор расшифровки и число реплик, но нет ни одного слова из реплик
