## ADDED Requirements

### Requirement: Вложения в обоих приложениях
Требования этой capability SHALL выполняться одинаково в `control-center` и в боковой панели `manager-helper`: прикрепление файлов кнопкой и перетаскиванием, загрузка до отправки с прогрессом и отменой, ошибки загрузки, файлы в сообщениях со скачиванием и сообщение о готовой расшифровке. Прикреплённые файлы MUST показываться над полем ввода плитками: иконка типа или миниатюра изображения, имя, размер, действие «убрать». В `manager-helper` скачанный файл MUST сохраняться под исходным именем средствами браузера.

#### Scenario: Прикрепление файла в manager-helper
- **WHEN** пользователь боковой панели прикрепляет PDF к сообщению
- **THEN** над полем ввода появляется плитка файла с прогрессом загрузки, после загрузки сообщение можно отправить

#### Scenario: Скачивание файла в manager-helper
- **WHEN** пользователь боковой панели нажимает на файл в сообщении
- **THEN** файл скачивается под исходным именем
