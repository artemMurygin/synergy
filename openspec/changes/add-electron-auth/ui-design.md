## Отклонения от architecture.md
- **Pages.** В `architecture.md` Pages нет; экраны выведены из состояний `AuthGate` (согласовано с пользователем). Структура файлов в `features/auth` не меняется.
- **Предупреждение при выходе без связи.** В архитектуре `LogoutButton` принимает `warning`. В дизайне после выхода пользователь уже на экране входа, поэтому предупреждение показывается там (Run Notice в `LoginForm`), а не рядом с кнопкой выхода. Для реализации: `warning` хранится в `SessionSnapshot` и выводится `LoginForm`; проп `warning` у `LogoutButton` не нужен.
- **Расширенный UI Kit.** Для Run Notice и Button использованы существующие компоненты; их тексты по умолчанию (например «Повторить» в Run Notice) отключены или переопределены. Действие «Повторить» в Run Notice скрыто.
