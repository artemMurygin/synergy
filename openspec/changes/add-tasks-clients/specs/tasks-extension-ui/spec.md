## Purpose

Компактный экран задач в side panel расширения manager-helper: быстрый доступ менеджера к своим задачам без перехода в desktop-приложение.

## ADDED Requirements

### Requirement: Переключение между чатом и задачами
Side panel SHALL позволять переключаться между «Чат» и «Задачи» в шапке панели. Переключение MUST не прерывать идущий ответ ассистента и не терять состояние чата. Последний выбранный раздел MUST запоминаться между открытиями панели. Раздел задач MUST быть доступен только после входа.

#### Scenario: Переключение во время ответа
- **WHEN** ассистент отвечает, а пользователь переходит в «Задачи» и возвращается
- **THEN** ответ продолжает приходить, чат показывает актуальное состояние

#### Scenario: Запоминание раздела
- **WHEN** пользователь закрывает панель на разделе «Задачи» и открывает её снова
- **THEN** открывается «Задачи»

### Requirement: Мои задачи
Экран SHALL по умолчанию показывать незавершённые задачи, где текущий пользователь ответственный, отсортированные по дедлайну (ближайшие первыми, без дедлайна — в конце). Строка содержит название, статус, дедлайн и метку просрочки текстом. Пользователь MUST иметь возможность переключить представление на «Наблюдаю», «Созданные мной» и «Готовые» и искать по названию. Список постраничный с подгрузкой по запросу пользователя.

#### Scenario: Открытие экрана
- **WHEN** пользователь открывает «Задачи»
- **THEN** показываются его задачи в статусах «К выполнению» и «В работе», ближайший дедлайн первым

#### Scenario: Просроченная задача
- **WHEN** дедлайн задачи в прошлом
- **THEN** строка подписана «Просрочено» и выделена акцентом

#### Scenario: Пустой экран
- **WHEN** у пользователя нет подходящих задач
- **THEN** показывается пустое состояние с действием «Создать задачу»

#### Scenario: Ошибка загрузки
- **WHEN** запрос завершился ошибкой
- **THEN** показывается сообщение и кнопка «Повторить»

### Requirement: Быстрое создание задачи
Пользователь SHALL создавать задачу из панели одним полем названия с необязательными дедлайном и ответственным (по умолчанию — текущий пользователь). Расширенные поля MUST быть доступны в раскрывающейся части формы. Отправка блокируется при пустом названии и во время запроса.

#### Scenario: Создание одним названием
- **WHEN** пользователь вводит название и подтверждает Enter
- **THEN** задача создаётся с ответственным «я», появляется в списке

#### Scenario: Ошибка сервера
- **WHEN** сервер отклонил создание
- **THEN** введённый текст сохраняется, показана ошибка

### Requirement: Смена статуса
Пользователь SHALL менять статус задачи одним действием из строки списка и экрана деталей. Изменение отражается сразу и откатывается с сообщением при отказе сервера.

#### Scenario: Закрытие задачи
- **WHEN** пользователь отмечает задачу выполненной
- **THEN** она получает статус «Готово» и исчезает из представления «Мои»

#### Scenario: Отказ сервера
- **WHEN** запрос смены статуса завершился ошибкой
- **THEN** статус возвращается, показано сообщение

### Requirement: Детали задачи
Пользователь SHALL открывать экран деталей: описание, дедлайн, создатель, ответственный, наблюдатели, вложения. Экран MUST позволять изменить название, описание и дедлайн, сменить ответственного и скачать вложение. Загрузка и удаление вложений в этом change не входят. Возврат к списку MUST сохранять позицию прокрутки и фильтр.

#### Scenario: Открытие деталей
- **WHEN** пользователь выбирает задачу в списке
- **THEN** открывается экран деталей, кнопка «Назад» возвращает к списку в том же состоянии

#### Scenario: Скачивание вложения
- **WHEN** пользователь нажимает на вложение
- **THEN** файл скачивается под исходным именем

#### Scenario: Задача удалена
- **WHEN** сервер отвечает 404 на загрузку деталей
- **THEN** показывается сообщение, пользователь возвращается к списку, задача убрана

### Requirement: Планшетный режим растянутой панели
Пользователь может растянуть side panel по ширине, поэтому раздел задач SHALL иметь версию для широкой панели. При ширине панели от 640 px (тот же порог, что у чата) раздел MUST показывать два столбца: слева список с представлениями и быстрым созданием, справа детали выбранной задачи. Пока задача не выбрана, правый столбец MUST показывать подсказку «Выберите задачу». Выбор задачи, смена статуса и редактирование MUST работать без перехода между экранами. При сужении панели ниже 640 px раздел MUST вернуться к одноколоночному режиму, сохранив выбранную задачу и фильтр.

#### Scenario: Панель растянута
- **WHEN** ширина панели становится 640 px или больше
- **THEN** список и детали выбранной задачи показываются рядом, кнопка «Назад» в деталях не нужна

#### Scenario: Задача не выбрана
- **WHEN** в широкой панели ни одна задача не выбрана
- **THEN** справа показана подсказка «Выберите задачу»

#### Scenario: Сужение панели
- **WHEN** пользователь сужает панель ниже 640 px при открытой задаче
- **THEN** открывается экран деталей этой задачи, возврат к списку сохраняет фильтр и прокрутку

### Requirement: Компактная вёрстка и сессия
Экран SHALL корректно работать при ширине панели от 320 px без горизонтальной прокрутки, все действия доступны с клавиатуры, статусы и просрочка передаются текстом. Обработка потери сессии и недоступности сервера MUST совпадать с поведением чата (общий слой авторизации).

#### Scenario: Узкая панель
- **WHEN** панель имеет ширину 320 px
- **THEN** строки задач переносят текст, горизонтальной прокрутки нет

#### Scenario: Потеря сессии
- **WHEN** во время работы с задачами сессия истекла
- **THEN** показывается экран входа, как в чате
