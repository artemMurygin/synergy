## ADDED Requirements

### Requirement: Число вложений в ответах о задаче
Система SHALL включать в представление задачи (элементы `GET /tasks`, ответы `GET /tasks/{id}`, `POST /tasks`, `PATCH /tasks/{id}`) поле `attachmentCount` — целое неотрицательное число вложений, прикреплённых к задаче. Подсчёт MUST выполняться для списка без дополнительных запросов на каждую задачу и MUST учитывать только существующие вложения.

#### Scenario: Список с вложениями
- **WHEN** клиент запрашивает список, где у одной задачи два вложения, а у другой ни одного
- **THEN** у первой задачи `attachmentCount` равно 2, у второй 0

#### Scenario: Удаление вложения
- **WHEN** у задачи удаляют одно из двух вложений
- **THEN** последующие ответы содержат `attachmentCount` равное 1

#### Scenario: Новая задача
- **WHEN** клиент создаёт задачу
- **THEN** ответ содержит `attachmentCount` равное 0
