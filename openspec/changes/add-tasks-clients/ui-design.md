# UI Design: add-tasks-clients

## Источник дизайна
- **.pen файл**: `design/synergy-design-kit.pen` (единственный файл дизайна в репозитории; шаблон схемы называет `sallary-first-iteration.pen` и фрейм `uDEum`, их в проекте нет, см. «Отклонения»).
- **UI Kit**: фрейм `Дизайн-система` (`OBWB5`) → `01 · Synergy UI Kit` (`k9JASi`). Использованы мастера: `Button / Master` (`pbEvR`), `Badge / Master` (`f4P4A`), `Chip / Master` (`xFsWD`), `Avatar / Master` (`e0G7e`), `Field / Master` (`b7hxv`).
- **Куда добавлены макеты**: `Control Center` (`tD0BP`) → `03 · Задачи` (`NbLWY`); `Manager Helper` (`DILPP`) → `07 · Задачи` (`uLRsP`).
- Токены: существующие `$brand-red`, `$ink*`, `$surface*`, `$border*`, `$info`, `$accent-green`, `$r-*`. Добавлены два новых: `$info-soft` (`#E9EFFC`), `$success-soft` (`#E6F4EC`) для фона статусов «В работе» и «Готово».

### Кодирование статуса (общее для обоих клиентов)
| Статус | Кружок слева | Бейдж |
|---|---|---|
| К выполнению | контур `$ink-40`, пустой | серый, точка `$ink-60`, текст «К выполнению» |
| В работе | контур `$info`, иконка часов | `$info-soft`, точка и текст `$info` |
| Готово | заливка `$accent-green`, галочка | `$success-soft`, точка и текст `$accent-green`; название строки `$ink-60` |
| Просрочено | иконка будильника + текст «Просрочено · дата» цветом `$brand-red` | статус-бейдж не меняется |

Статус всегда передаётся текстом, цвет — дополнительный сигнал.

## Новые компоненты UI Kit
Все сохранены как reusable в `05 · Молекулы` → `Row F` (`if3R4`) → `Panel Задачи (компоненты)` (`sPteO`).

| Компонент | Node ID | Где используется | Почему существующего недостаточно |
|---|---|---|---|
| `Task Row / Master` | `L8DdCa` | список control-center | Нет строки списка с кружком статуса, ответственным, дедлайном и бейджем |
| `Task Row Compact / Master` | `yEle2` | список manager-helper, состояния control-center | Нужна двухстрочная версия для 320–380 px |
| `Rail Item / Master` | `rWTJi` | рейл control-center | Нет вертикального пункта иконка + подпись с активным состоянием |
| `Attachment Row / Master` | `Na4df` | drawer, детали в расширении | Нет строки файла с действиями |
| `Segment Switch / Master` | `T1QKgz` | шапка side panel («Чат / Задачи») | Нет сегментированного переключателя |

Бейджи статуса сделаны как инстансы существующего `Badge / Master` с переопределением заливки, точки и текста, отдельный компонент не создавался.

## Отклонения от architecture.md
- Компонент `UserSearchSelect` в расширении отдельным макетом не рисовался: в быстром создании используются чипы «Дедлайн» и «Я · anna», а смена ответственного в режиме редактирования — поле `Field` (`Assignee Field`). Выпадающий список пользователей расширения повторяет `UserPicker` (`wUJGL`) в ширину панели.
- `AvatarStack` из architecture.md в макетах не понадобился: наблюдатели показаны чипами в drawer и перечислением логинов в расширении. При реализации компонент не создавать.
- Макеты и таблица ссылаются на `synergy-design-kit.pen` и его мастера вместо `sallary-first-iteration.pen` / `uDEum` из шаблона схемы: этих объектов в проекте нет.
- Добавлен планшетный вариант расширения по требованию пользователя (панель можно растянуть). Он не входил в первоначальный `architecture.md`; в нём добавлены `TasksSplitView` и `tasks-layout.ts`, правки внесены в `architecture.md`, `design.md` (D7a) и `specs/tasks-extension-ui`.
- Карта листа (`jxgk3`) не обновлялась: новые разделы не добавлены в её сводку.
