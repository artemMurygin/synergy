## Purpose

Формирует из описаний программ поисковые фрагменты и рассчитывает их векторные представления, чтобы агент подбора мог искать по смыслу без повторного расчёта неизменившегося текста.

## ADDED Requirements

### Requirement: Фрагменты текстовых разделов
Система SHALL сохранять текстовые разделы программы дословно в фрагментах соответствующего типа. Длинный раздел SHALL делиться на последовательные фрагменты по абзацам. Для каждой программы система SHALL формировать отдельный краткий фрагмент из названия, квалификации, уровня и краткой сути.

#### Scenario: Длинный раздел о карьере
- **WHEN** раздел о карьере превышает предел длины фрагмента и содержит несколько абзацев
- **THEN** система сохраняет несколько упорядоченных фрагментов типа «карьера» без пересказа исходного текста

#### Scenario: Карточка программы
- **WHEN** программа успешно загружена
- **THEN** у неё есть краткий поисковый фрагмент с названием, уровнем, квалификацией и доступной краткой сутью

### Requirement: Расчёт и обновление эмбеддингов
Система SHALL рассчитывать вектор для фрагментов без вектора после успешной записи каталога. Вектор MUST соответствовать текущему тексту и заданной размерности. Сбой расчёта MUST NOT откатывать уже сохранённый каталог; незавершённые фрагменты SHALL обрабатываться повторно.

#### Scenario: Текст не изменился
- **WHEN** фрагмент повторно загружен с тем же текстом
- **THEN** его существующий вектор сохраняется и повторный расчёт не требуется

#### Scenario: Текст изменился
- **WHEN** текст фрагмента изменился
- **THEN** прежний вектор не используется и рассчитывается новый для изменённого текста

#### Scenario: Провайдер недоступен
- **WHEN** расчёт векторов завершился ошибкой после успешной синхронизации листа
- **THEN** фрагменты остаются в каталоге без вектора и попадают в следующий цикл расчёта
