# chat-attachments-ui Specification

## Purpose
Прикрепление файлов к сообщению и показ файлов в сообщениях чата в приложении Electron (`control-center`), включая сообщение о готовой расшифровке, которое приходит в открытый чат.

## Requirements

### Requirement: Прикрепление файла
Поле ввода чата SHALL позволять прикрепить файл кнопкой выбора и перетаскиванием в панель чата. Можно прикрепить не более 5 файлов к одному сообщению. Выбор MUST ограничиваться допустимыми типами файлов. Прикреплённые файлы MUST показываться над полем ввода с именем, размером и действием «убрать».

#### Scenario: Перетаскивание записи
- **WHEN** пользователь перетаскивает `встреча.m4a` в панель чата
- **THEN** над полем ввода появляется карточка файла с именем и размером, начинается загрузка

#### Scenario: Шестой файл
- **WHEN** к сообщению уже прикреплено 5 файлов, и пользователь добавляет ещё один
- **THEN** файл не добавляется, панель сообщает об ограничении в 5 файлов

### Requirement: Загрузка до отправки
Файл SHALL загружаться на сервер сразу после прикрепления, с индикатором прогресса. Отправка сообщения MUST быть недоступна, пока хотя бы один файл загружается. Пользователь MUST иметь возможность отменить загрузку. Отменённый или убранный файл MUST NOT попадать в сообщение. Сообщение с загруженным файлом MUST отправляться и без текста.

#### Scenario: Отправка во время загрузки
- **WHEN** запись ещё загружается, и пользователь нажимает Enter
- **THEN** сообщение не отправляется, прогресс загрузки продолжает отображаться

#### Scenario: Отмена загрузки
- **WHEN** пользователь отменяет загрузку большой записи
- **THEN** загрузка прерывается, карточка файла исчезает, поле ввода снова доступно для отправки

#### Scenario: Только файл
- **WHEN** запись загружена, текст не введён, пользователь нажимает «Отправить»
- **THEN** в чате появляется сообщение пользователя с карточкой записи, начинается ответ агента

### Requirement: Ошибки загрузки
Панель SHALL показывать понятную причину ошибки прямо на карточке файла: неподдерживаемый тип, превышен размер (с допустимым лимитом), нет связи с сервером. Файл с ошибкой MUST NOT отправляться. Пользователь MUST иметь возможность убрать его или повторить загрузку.

#### Scenario: Неподдерживаемый тип
- **WHEN** пользователь прикрепляет `.exe`, переименованный в `.xlsx`, и сервер отклоняет его
- **THEN** на карточке написано «Этот тип файла не поддерживается», отправка с этим файлом недоступна

#### Scenario: Слишком большой файл
- **WHEN** сервер отклоняет документ из-за размера
- **THEN** на карточке написано, что файл больше допустимого, и указан лимит

### Requirement: Файлы в сообщениях
Сообщения пользователя и агента SHALL показывать вложения карточками: иконка по типу, имя, размер. Нажатие на карточку активного файла MUST скачивать файл через подписанную ссылку и сохранять его с исходным именем. Карточка удалённого файла MUST показываться неактивной с пометкой «Срок хранения истёк». В сохранённых сообщениях карточки MUST выглядеть так же, как сразу после ответа.

#### Scenario: Скачивание документа
- **WHEN** пользователь нажимает на карточку `Расшифровка — встреча.docx` в ответе агента
- **THEN** файл скачивается с этим именем

#### Scenario: Истёкший файл
- **WHEN** пользователь открывает старый чат, где файл ответа удалён по сроку
- **THEN** карточка файла неактивна и подписана «Срок хранения истёк»

### Requirement: Сообщение о готовой расшифровке в открытом чате
Если пользователь открыл чат, в который система добавила сообщение о готовой расшифровке, сообщение SHALL появляться в ленте без перезагрузки чата, по уведомлению в реальном времени. Если этот чат в данный момент не открыт, MUST показываться обычное уведомление, по которому можно перейти в этот чат. Сообщение системы MUST визуально отличаться от ответа на вопрос: у него нет хода работы агента.

#### Scenario: Чат открыт
- **WHEN** пользователь держит открытым чат, куда загрузил запись, и расшифровка завершилась
- **THEN** в ленте появляется сообщение с документом расшифровки, без перезагрузки

#### Scenario: Открыт другой чат
- **WHEN** расшифровка завершилась, а пользователь находится в другом чате
- **THEN** появляется уведомление, по нажатию на него открывается чат с сообщением о расшифровке
