# crm-gateway Specification

## Purpose

Определяет контракт доступа к CRM вуза (список обновлённых сделок и полная карточка сделки) и поведение мок-реализации, пока реальной CRM нет.

## Requirements

### Requirement: Список обновлённых сделок
Система SHALL предоставлять операцию получения идентификаторов сделок, обновлённых начиная с заданного момента времени, не включая сами карточки.

#### Scenario: Есть обновлённые сделки
- **WHEN** запрошены сделки, обновлённые после момента T
- **THEN** возвращается список id всех сделок с временем обновления позже T

#### Scenario: Обновлений нет
- **WHEN** после момента T сделки не обновлялись
- **THEN** возвращается пустой список без ошибки

### Requirement: Полная карточка сделки
Система SHALL предоставлять операцию получения полной карточки сделки по id. Карточка MUST содержать: id, ФИО клиента, телефон, образовательную программу, форму обучения, источник лида, этап воронки, `responsibleId`, время обновления.

#### Scenario: Сделка существует
- **WHEN** запрошена сделка с существующим id
- **THEN** возвращается карточка со всеми перечисленными полями, незаполненные поля передаются как пустые

#### Scenario: Сделка не найдена
- **WHEN** запрошена сделка с неизвестным id
- **THEN** возвращается явная ошибка «сделка не найдена», отличимая от ошибки доступности CRM

### Requirement: Мок-данные CRM
Пока реальный адаптер недоступен, система SHALL работать с мок-реализацией, возвращающей правдоподобные сделки по продаже высшего образования. Часть сделок MUST быть заполнена полностью, часть с намеренными пропусками обязательных полей. Мок MUST учитывать фильтр по времени обновления.

#### Scenario: Мок содержит полные и неполные сделки
- **WHEN** запрошены все сделки мока
- **THEN** в наборе есть как минимум одна полностью заполненная сделка и сделки с пропусками разных полей

#### Scenario: Фильтр по времени
- **WHEN** запрошены сделки, обновлённые после момента T
- **THEN** мок возвращает только сделки с временем обновления позже T
