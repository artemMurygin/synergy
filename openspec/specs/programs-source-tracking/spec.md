# programs-source-tracking Specification

## Purpose

Фиксирует, из каких листов Google-таблиц и из каких строк получены данные каталога, чтобы любое значение можно было проверить и перепарсить без повторной выгрузки, а нужные листы включать и отключать.

## Requirements

### Requirement: Реестр листов-источников
Система SHALL хранить реестр листов: идентификатор таблицы, идентификатор листа, название, хэш содержимого, время последней успешной синхронизации и признак включённости. Комбинация «идентификатор таблицы, идентификатор листа» MUST быть уникальной.

#### Scenario: Один лист один раз
- **WHEN** лист регистрируется повторно с теми же идентификаторами таблицы и листа
- **THEN** существующая запись обновляется, дубль не создаётся

#### Scenario: Отключение листа
- **WHEN** у листа признак включённости сбрасывается
- **THEN** лист остаётся в реестре и доступен для выбора «только включённые» без удаления данных

### Requirement: Сырые строки
Система SHALL хранить исходные строки листа в виде произвольной структуры вместе с номером строки и хэшем строки, привязанными к листу. Комбинация «лист, номер строки» MUST быть уникальной. Сырые строки MUST NOT содержать значений колонок, исключённых из загрузки как секретные.

#### Scenario: Обновление строки
- **WHEN** строка листа загружается повторно с изменённым содержимым
- **THEN** сырая строка обновляется, хэш меняется

#### Scenario: Строка без изменений
- **WHEN** строка листа загружается повторно с тем же содержимым
- **THEN** хэш остаётся прежним, что позволяет пропустить повторную обработку

### Requirement: Трассировка происхождения
Система SHALL позволять по программе, предложению и фрагменту содержимого определить исходную строку листа. Если сырая строка удаляется, связанные записи MUST NOT удаляться автоматически; ссылка в них MUST обнуляться.

#### Scenario: Откуда взята программа
- **WHEN** запрашивается происхождение программы
- **THEN** возвращаются таблица, лист и номер исходной строки

#### Scenario: Сырая строка удалена
- **WHEN** сырая строка удаляется при очистке
- **THEN** программа остаётся, а ссылка на исходную строку становится пустой

### Requirement: Очистка сырых строк листа
Система SHALL позволять удалить все сырые строки листа одной операцией без удаления самого листа из реестра.

#### Scenario: Полная перезагрузка листа
- **WHEN** сырые строки листа удаляются перед полной перезагрузкой
- **THEN** запись листа в реестре сохраняется, а строки отсутствуют
