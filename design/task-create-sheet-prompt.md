## Что изменилось в дизайне и зачем

Было: `QuickCreate` — серый блок на 168 px внутри колонки списка. Он выдавливал список вниз,
в строке действий одновременно жили подсказка «Enter — создать», «Отмена» и «Создать»,
а «Ещё» висело голой красной ссылкой без контейнера. На планшете форма оставалась в колонке
340 px, хотя правая панель 520 px в этот момент показывала заглушку «Выберите задачу».

Стало: создание — отдельный слой поверх раздела.

## Требования

### 1. Новый компонент `src/sidepanel/tasks/TaskCreateSheet.tsx`

Заменяет `QuickCreate.tsx` (старый файл и его тест удалить, покрытие перенести).

Слой:
- оверлей на всю секцию задач: `fixed inset-0 z-30 flex bg-ink/45` (на узкой — `items-end`,
  на широкой — `items-center justify-center p-4`);
- контейнер: `role="dialog" aria-modal="true" aria-label="Новая задача"`;
- узкая панель: `w-full rounded-t-2xl bg-white shadow-[0_-4px_24px_#00000026]`;
- широкая (`isWidePanel(widthPx)` из `../panel-layout`): `w-150 max-w-full rounded-2xl
  shadow-[0_12px_32px_#00000033]`, без «хватки».

Шапка:
- узкая: «хватка» `h-1 w-9 rounded-full bg-[#cacacb]` по центру, под ней строка `h-11
  px-4 pr-3`: заголовок «Новая задача» (`font-heading text-base font-semibold`) + распорка +
  кнопка закрытия 28×28 (`CloseIcon`, `text-ink-60`, `aria-label="Закрыть"`);
- широкая: та же строка, но `h-14 pl-6` и заголовок `text-lg`.

Тело:
- название — `<input>` без рамки, `autoFocus`, `aria-label="Название задачи"`,
  `placeholder="Название задачи"`, `font-heading text-lg font-semibold text-ink
  placeholder:text-ink-40`;
- описание — `<textarea rows={2}>` без рамки, `aria-label="Описание"`,
  `placeholder="Добавить описание…"`, `text-sm`;
- три строки-поля (`h-12 px-4` на узкой, `h-11` в диалоге, разделитель `border-b
  border-[#e8e8ea]`), каждая — `<button type="button">` с `aria-haspopup="dialog"`:

  | Строка | Иконка | Значение по умолчанию |
  | --- | --- | --- |
  | Дедлайн | `CalendarIcon` | «Не указан» (`text-ink-40`) |
  | Исполнитель | `UserIcon` | «Я · {login}» |
  | Наблюдатели | `UsersIcon` (добавить в `icons.tsx`) | «Добавить» (`text-ink-40`) |

  Разметка строки: иконка 18 (`text-ink-40`) → лейбл `text-sm font-medium text-ink` →
  распорка → значение `text-sm font-semibold` → `ChevronRightIcon` 16 (`text-ink-40`).

Футер:
- узкая: `px-4 pt-4 pb-5`, кнопка на всю ширину `h-12 rounded-xl bg-brand-red text-[15px]
  font-semibold text-white`, под ней подсказка по центру `text-xs text-ink-60`;
- широкая: строка `px-6 py-3.5 border-t`, слева подсказка, справа «Отмена» (ghost) и
  «Создать задачу» (`h-9 rounded-xl`);
- текст кнопки — «Создать задачу»; при пустом названии `disabled:bg-ink-40` без тени,
  подсказка меняется на «Введите название, чтобы создать задачу» (узел `lY4l4`);
- во время запроса кнопка блокируется, лейбл «Создаём…» + `LoaderIcon`.

Ошибка (`WYzRT`): полоса над футером — `border-t border-[#e8e8ea] bg-brand-red-soft px-4 py-2.5`,
`AlertCircleIcon` 16 `text-brand-red` + текст `text-[13px] text-ink`, контейнер `role="alert"`.
Текст из `messageOf(failure)`. Черновик при ошибке сохраняется, подсказка под кнопкой —
«Текст сохранён — попробуйте ещё раз».

### 2. Второй уровень шторки: `src/sidepanel/tasks/DeadlinePicker.tsx`

Экран `MkR4S`: та же шторка, шапка с кнопкой возврата (`ArrowLeftIcon` 28×28) и заголовком
«Дедлайн», тот же крестик справа. Список опций `h-13 px-4`, у выбранной — красная иконка,
полужирный лейбл и `CheckIcon` `text-brand-red` справа:

| Опция | Значение |
| --- | --- |
| Сегодня | сегодня, 18:00 |
| Завтра | завтра, 10:00 |
| Следующий понедельник | ближайший пн, 10:00 |
| Без срока | `deadline: null` |
| Выбрать дату и время | открывает нативный `datetime-local` |

Значение уходит в API через существующий `fromLocalInput` из `./format`. Быстрые варианты
считать чистой функцией в `format.ts` (`quickDeadlines(now)`) и покрыть юнит-тестом на
границах (конец месяца, воскресенье).

Исполнитель и наблюдатели открываются тем же вторым уровнем: заголовок + `UserSearchSelect`
(`aria-label="Ответственный"` сохранить — на него опираются тесты). Для наблюдателей нужен
множественный выбор: выбранные показываются чипами с крестиком, значение уходит в
`watcherIds`. Если множественный режим `UserSearchSelect` выйдет дороже остальной работы —
сделать его отдельным шагом и на первом этапе оставить строку «Наблюдатели» скрытой;
макет без неё не ломается.

### 3. `src/sidepanel/tasks/TasksSplitView.tsx`

- `QuickCreate` больше не рендерится внутри колонки списка — вместо него `TaskCreateSheet`
  рендерится после `<div className="flex min-h-0 flex-1">`, то есть поверх обеих колонок;
- `creating` и колбэки (`onCreated` → `setCreating(false)` + `reload`, `onCancel`) не меняются;
- `aria-expanded` на кнопке «+» в `PanelHeader` сохранить;
- пустое состояние списка (`TaskList onCreate`) продолжает открывать ту же шторку.

### 4. Поведение и доступность

- открытие: «+» в шапке и «Создать задачу» в пустом состоянии списка;
- закрытие: крестик, `Esc`, клик по затемнению. На втором уровне `Esc` возвращает на первый;
- `Enter` в поле названия создаёт задачу (как сейчас), `⌘/Ctrl + Enter` — из любого поля;
- фокус: при открытии — на поле названия, при закрытии — обратно на кнопку «+»;
  фокус-ловушка внутри слоя, фон `inert` или `aria-hidden`;
- черновик живёт, пока шторка открыта: закрытие сбрасывает форму (как «Отмена» сейчас).

## Критерии приёмки

1. Создание задачи больше не занимает место в колонке списка ни на одной ширине: список
   не сдвигается при открытии формы.
2. На планшете (≥ 640) форма — диалог 600 px по центру поверх затемнённого сплита; правая
   панель не подменяется формой и не показывает заглушку вместо неё.
3. Поля ровно те, что поддерживает API: название, описание, дедлайн, исполнитель,
   наблюдатели. Никаких приоритетов, напоминаний и вложений в форме создания.
4. Пустое название → кнопка неактивна и подсказка объясняет, почему.
5. Ошибка сервера не стирает введённое: текст и выбранные значения остаются, сообщение
   показано полосой над кнопкой и доступно скринридеру.
6. `Esc`, крестик и клик по затемнению закрывают шторку; фокус возвращается на «+».
7. Логика создания (`createTask`, `fromLocalInput`, `messageOf`), переключение разделов и
   общая шапка панели не меняются — правка затрагивает только слой создания задачи.
