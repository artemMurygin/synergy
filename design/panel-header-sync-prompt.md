## Что изменилось в дизайне и зачем

Шапка чата и шапка задач разъехались: переключатель «Чат / Задачи» был только в разделе
задач и в правой колонке чата (а в окне списка чатов отсутствовал вовсе), кнопки создания
отличались (иконка `square-pen` в чате, подписанная красная кнопка «Новый чат» в списке,
иконка `plus` в задачах), шестерёнка дублировалась. Теперь во всех состояниях обоих
разделов — одна общая шапка панели.

**Целевая структура (одинакова для чата и для задач, при любой ширине):**

```
┌───────────────────────────────────────────────┐
│ [Чат | Задачи]                   [ + ]  [ ⚙ ] │  ← общая шапка панели, 56 px, на всю ширину
├───────────────────────────────────────────────┤
│ [←] Заголовок экрана                          │  ← контекстная строка, 48 px (только там, где нужен заголовок/возврат)
├───────────────────────────────────────────────┤
│ содержимое раздела                            │
└───────────────────────────────────────────────┘
```

## Требования

### 1. Новый компонент `src/sidepanel/PanelHeader.tsx`

Общая шапка панели:
- `<header>`: `flex items-center gap-2 border-b border-line px-3 py-2.5` → высота 56 px;
- слева — существующий `SectionSwitch` (компонент не меняется), затем распорка `flex-1`;
- справа — две иконочные кнопки 36×36 (`size-9 rounded-lg hover:bg-surface-alt`):
  - основное действие: иконка `PlusIcon`, цвет `text-brand-red`;
  - настройки: иконка `SettingsIcon`, цвет `text-ink-60`, `chrome.runtime.openOptionsPage()`.
- Пропсы примерно: `{ switcher: ReactNode; actionLabel: string; onAction: () => void;
  actionDisabled?: boolean; actionExpanded?: boolean; onOpenSettings: () => void }`.
- `aria-label` основной кнопки задаётся разделом: «Новый чат» в чате, «Новая задача» в задачах
  (в задачах сохранить `aria-expanded`, как сейчас в `TasksSplitView`).

Шапка рендерится **над обеими колонками**, а не внутри списка. Состояние `QuickCreate`
поднимать не нужно: рендерь `PanelHeader` в двух местах — в `App.tsx` для секции чата и в
`TasksSplitView` над сплитом. (Альтернатива — один рендер в `App.tsx` с подъёмом колбэка
создания задачи; допустима, если так выйдет чище.)

### 2. `src/sidepanel/ChatHeader.tsx` → контекстная строка

Переименовать по смыслу (например, `ChatTitleBar`) и оставить только:
- кнопку возврата к списку (`ListIcon`, `aria-label="К списку чатов"`), показывается по
  `paneVisibility(...).backToList`, размер 32×32 (`size-8 rounded-lg`), цвет `text-ink`;
- заголовок чата: `min-w-0 flex-1 truncate text-base font-semibold text-ink`, фолбэк «Новый чат»;
- индикатор «агент отвечает» (точка `bg-brand-red`) — оставить рядом с заголовком.

Контейнер: `flex items-center gap-2 border-b border-line px-3 py-2` → 48 px.
**Удалить из него:** проп `sectionSwitch`, кнопку «Новый чат» (`NewChatIcon`), кнопку настроек.
Пропсы `onNewChat`, `newChatDisabled`, `onOpenSettings`, `sectionSwitch` убрать.

### 3. `src/sidepanel/ChatSessionList.tsx`

- Из шапки списка **убрать красную подписанную кнопку «Новый чат»** (константа `primary`
  остаётся только для кнопки «Начать чат» в пустом состоянии — она в макете сохранена).
- Шапка становится контекстной строкой 48 px: кнопка «Назад к чату» (`ArrowLeftIcon`, 32×32,
  показывается как сейчас по `onBack`) + заголовок «Чаты».
- Пропсы `onCreate` / `createDisabled` остаются только для кнопки пустого состояния.

### 4. `src/sidepanel/App.tsx`

- Секцию чата сделать колонкой: `PanelHeader` (switcher, действие «Новый чат» → `createChat`,
  `actionDisabled={creating}`) сверху, под ней текущий ряд «список + чат».
- Переключатель раздела больше не передаётся в `ChatHeader`; `sectionSwitch` уходит в `PanelHeader`.
- Важное поведенческое следствие: переключатель «Чат / Задачи» виден во **всех** состояниях,
  включая узкое окно списка чатов (раньше там его не было) и экран деталей задачи.
- Ширину колонки списка чатов при широкой панели привести к колонке задач: `w-75` → `w-85`
  (300 → 340 px), как в макете `D13EfJ` / `Z06fX`.

### 5. `src/sidepanel/tasks/TasksSplitView.tsx`

- Текущую `<header>` (switcher + «+» + ⚙) **вынести из левой колонки** на уровень секции:
  обернуть содержимое в `flex min-h-0 flex-1 flex-col`, сверху `PanelHeader`, под ним
  существующий ряд панелей. Сейчас шапка живёт внутри колонки `w-85` и на широкой панели
  не растянута на всю ширину — это и есть расхождение с макетом.
- Разметку и логику `QuickCreate`, `TasksToolbar`, `TaskList`, `TaskDetails` не трогать.

### 6. Чего быть не должно после правок

- Второй кнопки создания чата (иконка `square-pen` рядом с шестерёнкой) — удалить
  `NewChatIcon` из использования, иконку из `icons.tsx` убрать, если больше не нужна.
- Второй шестерёнки: настройки открываются только из общей шапки.
- Подписанной красной кнопки «Новый чат» в шапке списка чатов.
- Переключателя раздела внутри заголовка чата или внутри колонки списка задач.

## Критерии приёмки

1. Переключатель «Чат / Задачи» находится в одной и той же точке (левый край шапки, 56 px)
   на всех экранах обоих разделов и при любой ширине панели — он не смещается при переходах.
2. Кнопка создания одна на раздел, визуально идентична в чате и в задачах: иконка «плюс»
   36×36, цвет `brand-red`, прозрачный фон.
3. Шестерёнка одна, в правом верхнем углу, цвет `ink-60`.
4. На широкой панели (≥ 640 px) шапка растянута над обеими колонками в обоих разделах,
   ширина левой колонки 340 px и там, и там.
5. На узкой панели под шапкой идёт строка 48 px с кнопкой возврата и заголовком
   («Цены на МВА» / «Новый чат» / «Чаты»), содержимое не обрезается по нижней границе.
6. Логика создания чата/задачи, переключения разделов, `QuickCreate` и быстрого подбора
   не изменилась — это чисто структурная правка шапки.
